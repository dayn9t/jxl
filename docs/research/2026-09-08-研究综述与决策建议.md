## 2. 验证问题汇总与分级

四份均无 major（verdict 全为 minor_issues，主路线未推翻）。以下 A 级按「会误导实操决策 / 与我方实证矛盾 / 改变规则设计」标准从 minor 中析出，**采纳对应结论前必须先修正**；B 级为引用、数字、表述强度问题，修正措辞后即可引用。

### 2.1 A 级：采纳前必须修正（12 条）

| # | 来源/位置 | 问题 | 修正动作 |
|---|---|---|---|
| A1 | cls §2.2/§5 | 「`scale=0.0` → RRC 退化为纯 resize（无损）」**错误**：classify 路径 ratio 固定 (0.75,1.333) 不可配，高瘦 crop 在比例越界时 10 次采样失败回退为按 ratio 钳制的中心裁剪（200×500 → 200×267，切掉 ~47% 高度）——恰是 §2.1 指控的同一毒点 | pad-to-square 从「最重要的一条」**升格为前置依赖**：scale 调整以 pad-to-square 为前提；配方表注明 classify 路径 ratio 不可配 |

## 3. 三项待决事项的直接建议

### 3.1 (a) 属性词典终稿：属性集与操作化定义

**属性集**（维持构想存档 §5 的骨架，全部保留）：

| 属性 | 类型 | 终稿建议操作化定义 | 业界依据 |
|---|---|---|---|
| non_person / person_upper / person_full / person_partial | 互斥四粗类（one-hot） | 定义见下三行；组内互斥=UPAR Age/Hair 三选一同构 | UPAR 12 类目含显式组内互斥 |
| is_person（=四粗类的 non_person 判定） | 判据+负面判例清单 | 框内**像素主体**为真人或其一部分；负面判例：海报/照片/屏幕人像、雕像、人体模型、**玩偶/毛绒玩具（红毛绒判例）**、镜面倒影 → non_person；只有一只手 → 是人的部分 | CityPersons fake humans 标 ignore（https://arxiv.org/abs/1702.05693 ） |
| person_full | 粗类 | 头+躯干+下肢三区均可见 ≥50%（amodal 分母）；髋以下隐约可辨→不算 full | CityPersons full box（amodal）思想 |
| person_upper | 粗类 | 头或躯干可见，下肢 <50% 可见（截断/遮挡）；**柜台截断=一等分布** | RAP occlusion 来源显式含 desk/camera border（https://arxiv.org/abs/1603.07054 ） |
| person_partial | 粗类 | 头 <50% **且**躯干 <50%，仅肢体/衣物碎片（一只手臂/一条腿/衣角/露头顶 30%） | CrowdHuman heavy/partial 分层 + PARSE-27K 出画面边界 N/A |
| upper_body_visible | 布尔 | **躯干（肩线至腰）轮廓可见 ≥50%**；手臂从必要条件降为辅助证据；柜台挡到胸口仍=1，只露肩膀=0 | RAP 明言手臂在监控下不可可靠标注故只标 3 粗部位框 |
| head_visible | 布尔 | 头顶至下颌头形轮廓 ≥50%（含头发/后脑）；**戴帽=1**；后脑勺=1；只剩下巴=0 | CrowdHuman hbox 一等标注；hat 为独立属性不改头部可见性（RAP/MSP60K/UPAR 一致） |
| face_visible | 布尔 | 面部区域（额头-下颌、左右耳前）≥50%，正/侧脸均可；**口罩/墨镜=1**（判据是区域不是五官）；后脑勺=0；俯拍只见头顶=0 | **业界无先例**（RAP 弃细部位），全自建+重点抽检 |
| is_partial | 布尔（校验镜像） | = person_partial 粗类的布尔镜像；建议**保留**（双问冗余=免费交叉质检信号，R6 规则依赖它） | —（vlm 调研 §2.2 权衡论证） |
| uncertain | 第三态 | 判据落 borderline（约 40–60% 可见）或证据矛盾 → uncertain；光线极差/运动模糊同 | UPAR unknown / PARSE-27K N/A / BAP unspecified |

**通用约定（词典头部写死，逐字复用于 VLM prompt/分类器验收/人工终审）**：

1. **image-level**：仅依据当前帧可见证据，不做身份推断、不跨帧传播（identity-level 反面教材=PETA）。
2. **amodal 分母**：「所有可见比例均相对于该身体部位的完整大小估计，不是相对于检测框」——不写死则柜台截断下可见性语义全错（CityPersons/CrowdHuman amodal 教训）。
3. **判例式边界**：每属性 2–3 条问答判例入 prompt（UPAR 补充材料风格：「打底裤算下装长吗？算。长靴算吗？不算。」）。
4. **uncertain 处置（A11 修正版）**：uncertain **不入分类器训练集，但保留入库打 uncertain 标**（供口径迭代/重审），触发 doubao 二审；uncertain 率作词典健康度指标（某属性突增=措辞漂移信号）。
5. **一致性校验 R1–R6** 放代码层后验（见 §3.2），规则集随词典终稿同步。
6. **切分纪律**：属性库 train/val/test 切分以 dino 聚类簇为原子，禁止同簇跨 split（identity 泄漏对策，PA-100K tracklet 切分同构）。

**需用户拍板的 2 个开放项**（建议与词典终稿一并）：

- 可见比例阈值形态：单一 ≥50%（首版建议——实现最简、与三态 enum 对齐）vs 三档（<50%/borderline uncertain/>50%）vs VLM 连续分数校准后入库（等金标校准基建跑通再评估）。
- face_visible 正例率：先统计 18,999 框 VLM 回收数据实测（A10），据实决定是否定向补正面样本。

### 3.2 (b) VLM 批量标注 schema 与质控要点

**schema 要点**（以 vlm 调研 §1.5 草案 v0 为基础，并入修正）：

| 项 | 建议 | 依据/修正 |
|---|---|---|
| 调用形态 | **单 crop 单调用**，不做多 crop batching（图像 token 是大头，省小头引串扰） | arXiv 2604.03684（https://arxiv.org/html/2604.03684v1 ）批量维度证据 |
| 字段数 | 6 判定字段 + note ≈ 7，落在 k≤10 安全区，无需拆组——**视觉域拐点未验证，500 crop A/B 确认**（拆组预案：coarse+is_partial / head+face+upper_body） | 同上（文本域证据+加性结论） |
| 字段类型 | 三态 enum（yes/no/uncertain）；字段名自释义；schema 同时写进 prompt（vLLM 官方 tip） | instructor（命名 4.5%→95% 摆动）；vLLM docs（https://docs.vllm.ai/en/latest/features/structured_outputs/ ） |
| 约束解码 | vLLM structured_outputs（v0.12.0 起，OpenAI 兼容 response_format json_schema）；**enum/additionalProperties 按 dotjson 矩阵为 Unsound——首请求验证**（A12）；doubao 侧 response_format json_schema（beta）同 schema 双标（方言差异各跑一次最小 schema） | dotjson（https://blog.dottxt.ai/json-schema-comparison.html ）；火山方舟（https://docs.volcengine.com/docs/82379/1568221 ） |
| 蕴含校验 | **代码层后验**，不放 schema：R1/R2 定义性蕴含（face→head）自动修复+provenance 记账；R3–R6 语义矛盾（non_person 却 face=yes 等）L2 带违例说明自纠重试 1 次（temperature=0 下盲重试无效）→仍败全字段 uncertain 进人审，绝不静默改数 | xgrammar 组合关键字不支持且部分 Unsound |
| 调用参数 | temperature=0；max_tokens ~200；**thinking 关**（`enable_thinking:false`，结构化提取 6× 延迟 5× token 且有 vLLM 兼容开关坑） | j-qwen-local-deploy 教训；vLLM docs Reasoning 节 |
| 记账 | stem/model_id/schema_ver/prompt_ver/finish_reason/retry_count/latency_ms/raw_response 双写不删 | provenance 制度（数据飞轮调研 §7.3） |
| 词典同步 | schema 内 description 与属性词典**逐字一致**——现草案 coarse_class 描述仍含「至少一臂」旧口径，词典终稿后须同步改 | 防口径漂移（构想存档 §6） |

**质控要点**：

| 环节 | 方案 |
|---|---|
| 分层抽检 | doubao：高置信层 5% / uncertain 层 50% / 违例层 100%（+人审）——5-10% gold 审计为行业口径（https://labelstud.io/learning-center/how-to-run-a-pilot-before-committing-to-annotation-vendor/ ） |
| 一致率解读 | **报 Cohen's κ 为主指标**（裸一致率被属性偏斜虚高）；对齐人类基线（κ 0.63–0.88、分歧 6–21%）解读；分歧=路由信号非失败（qwen↔doubao 不一致滚动进双标层） |
| 置信度 | **不让模型自报分数**（verbalized confidence 系统性过自信）；需要连续分数时用 logprobs 在冻结金标上温度缩放 |
| 金标 | ~500–1,000 crop 冻结金标集（dino 簇×属性取值分层，人审后永不入训练）；per-attribute reliability diagram 校准，P(正确) 低的属性强制双标 |
| 人检压缩 | 沿毒标注审计打法：dino 簇×双标一致层×属性取值三维分层，簇代表必检（3.5 万框可压到数百簇代表+尾部全检） |
| 前置试跑 | **500 crop 试跑三产出**：① qwen3.5-35b 对 structured_outputs 兼容性（schema 编译+enum/additionalProperties 接受行为，issue #26421 模糊报错早暴露）；② A/B（6 字段打包 vs 拆组、note 有无、thinking on/off）；③ 吞吐外推（容量算法：35,000×(视觉 token+前缀+输出)÷vllm bench 实测，勿抄文本负载结论） |

### 3.3 (c) 分类器训练配方关键参数（修正版）

**前置（最高优先）**：crop **pad-to-square 落盘**，且 **pad 策略统一**（全部常数灰或全部 context/mirror；不混合——防「灰条=partial」捷径，A3）；serving 预处理严格复刻同一策略；归一化仅 /255（yolo26-cls 无 ImageNet mean/std）。

| 参数 | 四粗类 coarse4 | 布尔属性（head/face…） | 修正/依据 |
|---|---|---|---|
| model | yolo26l-cls（**14.1M**，top1 79.0） | yolo26m-cls（11.6M，78.1）起步 | 构想存档 §2 的「~19M」须勘误；l/m 在我方 crop 分布的差未实测——**首轮各训一个对比再定档** |
| 数据组织 | 4 类目录 / yes-no 两目录；**自行落盘三 split**（帧级/dino 簇级隔离，勿用自动切分） | 同左 | 类索引=字典序（non_person=0/person_full=1/person_partial=2/person_upper=3），以 model.names 为准 |
| scale | 0.0~0.1（**仅 pad-to-square 后安全**，A1） | 0.0 | classify 路径 RRC ratio 固定不可配 |
| auto_augment | `''`（关 RandAugment 几何算子） | `''` | 关后 ColorJitter 生效 |
| erasing | 0.0（≤0.1 可试） | **0.0（必须——头可能被抹掉）** | |
| hsv_h/s/v | 0.01 / 0.3 / 0.4 | 同左 | 0.7 默认过强；照度抖动保留（固定机位白天/灯光） |
| fliplr/flipud | 0.5 / 0.0 | 同左 | 无朝向语义 |
| epochs/patience/dropout | 80 / 20 / 0.1 | 50 / 20 / 0.1~0.2 | patience 默认 100≈不早停 |
| optimizer | auto（>10000 iterations → MuSGD 0.01；否则 AdamW ≈0.00125@nc=4）；loss 抖动则显式 AdamW lr=0.001 | 同左 | |
| freeze | None（全量 finetune 优先；过拟合再试 **freeze=10**，A2） | None | freeze=9 会漏 model.9 C2PSA |
| batch/imgsz | 64~128 / 224 | 同左 | 224 与预训练一致 |
| 类不平衡 | 目录级过采样（symlink）+ 推理侧调 P(positive) 阈值；**无 class weights**（裸 F.cross_entropy） | 同左 | 引文按 A4 修正后引用 |

**验收**（修正版）：
- 主线=混淆矩阵行 recall：non_person 行（毒框拦截）+ person 行（不误杀）；草案 ≥0.98/≥0.99，首轮实测与用户定标；nc≤5 时 top5 恒 1.0 忽略。
- 毒框验收集：**显式 hold-out**（与训练集互斥，A5）+ 补随机负例抽样集（覆盖挂衣/椅子/海报/反光等其余 FP 家族）。
- 集外把关：新时段抽样集（未参与任何标注轮次）做最终验证。
- 部署：torch 直出（fuse+half），实测 6×m fp16 2.34 ms/crop、427 crops/s（4060Ti），全族一帧 <0.1s 富余；进阶 ONNX dynamic / TensorRT optShapes。

## 4. 采纳路线：对接构想存档 §8 启动条件

### 4.1 可直接采纳（验证后站得住，无需修改）

1. **属性词典方向**：PAR 无可见性属性、操作化借检测侧 amodal/visible 双框+RAP 粗部位框；image-level 口径；四粗类互斥有 UPAR 先例；CityPersons 假人 ignore=红毛绒负面判例同构；词典三方同口径防漂移。
2. **数据纪律**：属性库切分以 dino 簇为原子（identity 泄漏对策）；uncertain 第三态不入训练；金标冻结永不入训练。
3. **VLM 标注**：单 crop 单调用 k≤10（文本域证据+500 crop A/B 对冲）；三态 enum+字段名自释义；约束解码；蕴含校验代码层+分级处置；doubao 分层抽检+Cohen's κ；不信自报置信。
4. **分类器配方**：默认增强三毒点结论；pad-to-square 必要性（升格前置）；无 class weights→过采样+阈值；类索引字典序；自行三 split；全族 4060Ti 直出部署。
5. **飞轮机制**：冻结金标重建先行（0.895 虚高）；三层混合干跑+少数派否决；复训顺手 2 折 OOF（一次训练产模型+OOF 预测两资产）；VLabel 的 accept/edit/reject 落 (crop,属性,裁决) 三元组入库；重训触发草案（5% 锚点/连续增益 ε 为草案，首轮实测标定）。
6. **可选扩展**：补 EV（漏标/exhaustiveness）维度为独立布尔分类器——我方体系现只查「框对不对」不查「该标的标了吗」。

### 4.2 按启动条件逐条对接

| §8 条件 | 现状 | 综述处置 |
