## 1. 本次工作

### 1.1 sgcc 前景感知去重（20124 → 18384，-8.6%）

**背景**：审查发现当前 sgcc（20124 图）**未经任何去重**——旧 2026-06-25 SemDeDup pipeline 针对的是更早的 14284 旧 samples 池，产物（samples_dedup 13299）从未进训练；当前 sgcc 是实体复制 + video-extract 合并重构，完全绕过去重。video-extract 视频抽帧 + 监控同人多次 → 近重复 + train/val 泄漏风险。

**复用** 2026-06-25 前景感知 pipeline（背景同质，整图去重失效，改 person crop；通用方法见 kb `20260710-foreground-aware-dedup.md`）：
1. `person_crop`：YOLO bbox 截前景 crop（忽略同质背景），20124 图 → 55991 crop
2. `person_embed`：DINOv2-small 384d SSL embedding（GPU ~1.5min）
3. `person_dedup`：SemDeDup（Faiss cos≥0.95 + 并查集）→ 55991 → 45151 近重复代表
4. `samples_dedup`：整图姿态簇指纹（frozenset）去重，相同姿态组合留 1

**结果**：20124 → 18384（-8.6%）。video-extract 5840→5146（-11.9% 静止段冗余），监控 top_ 7904→7217（-8.7% 同人多次），1_/2_ 4189→3937。533 负样本保留。阈值 0.95 保守（部分视频去重 0，证明无误删）。

**工具修复**（commit 05e004b）：
- `person_crop`：极小 bbox 经 jvi roi round 后尺寸为 0 → cv2.imwrite crash → 加空 crop 防护（skip 32 远景小人）
- `samples_dedup`：无 person crop 图（533 负样本空标 + 15 退化 bbox）被误丢 → 改为原样保留（负样本对训练假阳抑制重要；通用教训见 kb `20260710-foreground-aware-dedup.md`「去重不能丢负样本」）

### 1.2 本机 person.pt 微调失败（负优化，已废弃）

**配置**：person.pt + lr0=0.01（默认）+ patience 50 + epochs 200

**结果**：EarlyStopping 停在 ep51，best 卡 ep1 mAP50-95=0.689（**低于 person.pt 原本 0.720**，负优化）。ep1 warmup 后 mAP 跌到 0.614。

**根因**：lr0=0.01 微调已收敛 person.pt → catastrophic forgetting 破坏已学特征 + patience 从 ep1(0.689) 计数致过早早停。**完整根因/解法/判断规则见 kb `20260710-finetune-must-lower-lr0.md`**（解法：微调 lr0=0.001 + freeze=10）。

**输出位置跑偏**：ultralytics `project="runs/detect"` 相对路径被拼到 SETTINGS runs_dir，save_dir 误存 `/home/jiang/py/js4/...`（通用根因/解法见 kb `20260710-yolo-training-deploy-sop.md` §6）。

### 1.3 转 sgcc0 从头训（yolo26n.pt COCO 预训练）

**配置**：yolo26n.pt（COCO 80 类预训练，非随机初始化——措辞见 kb `20260710-yolo-training-deploy-sop.md` §9）+ sgcc-only（18384）+ 默认 lr0=0.01 + patience 30

**rsync**：9.3G 数据 → sgcc0（内网 12 MB/s，13min；非存档的 VPN 0.4MB/s）

**趋势**（截至发文 ep30）：best ep29 mAP50-95=0.862（**超 person.pt 0.720 达 +0.142**），mAP50=0.977，持续上升（无进步 0/30）。从头训 + 默认 lr0 路径正确（首次域迁移，标准迁移学习安全，见 kb `20260710-finetune-must-lower-lr0.md` 对比表），无微调破坏问题。

### 1.4 yolo_train.py 完善（commit ec061fe）

补 `--lr0/--lrf/--freeze/--optimizer/--cos-lr/--close-mosaic` 透传 ultralytics（原漏透 lr0/freeze 间接导致 §1.2 失败无法现场纠正；通用教训见 kb `20260710-yolo-training-deploy-sop.md` §8）；`project` 自动 `Path.resolve()` 绝对化，根治 save_dir 跑偏。已同步 sgcc0。
