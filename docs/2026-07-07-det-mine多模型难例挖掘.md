> Cross-detector 加权争议分 + cascade 难例挖掘系统。person.pt(target) + YOLOE/GroundingDINO/RF-DETR(3 校验器) 多模型共识，争议分分级（L0 丢 / L1 自动标注 / L2-L3 review 候选集），最小化人工。

## 1. 背景与目标

升级 `person_mine`（二元共识 person.pt vs YOLOE）为 N 模型加权争议分 cascade，解决：
- 二元粗糙（无法区分全员分歧 vs 边缘分歧）
- 单模型误差污染标注（YOLOE 错 → 标注错）
- 无优先级（5840 样本不知先复核哪个）

目标：**最小化人工**的高质量自动标注，cascade 逐级过滤到人工只剩"模型也拿不准"的少量样本。

### CLI
```bash
det_mine <frames_dir> <out_dir> \
    --target person --target-model /opt/howell/iap/current/ias/model/person.pt \
    --validators yoloe,gdino,rfdetr --consensus 2 \
    --validator-weights rfdetr:0.4,gdino:0.35,yoloe:0.25 \
    --review-top 0.3 --device cuda:0
```
- `--target` → GDINO prompt + YOLOE set_classes（多类零改代码：`--target phone --target-model phone.pt --rfdetr-cls-id 67`）
- `--review-top 0.3`（比例）或 `--review-threshold <float>`（绝对分）二选一控制 review 分流
- `--force` 覆盖非 det_mine 产物目录
