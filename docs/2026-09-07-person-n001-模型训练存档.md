## 4. 结果

### TEST 终评（best.pt，1,379 帧 / 1,925 框）

| 指标 | 本次 | 上次生产模型 | Δ |
|---|---|---|---|
| P | **0.9653** | — | |
| R | **0.9380** | — | |
| mAP50 | **0.9715** | 0.956 | +0.016 |
| **mAP50-95** | **0.8952** | 0.720 | **+0.175** |
| 推理 | 2.4ms/图(4060Ti) | 0.5ms/图(4090) | 不同卡不可比 |

- val 曲线：epoch 3 mAP50 已 0.86+，epoch 200 val mAP50 0.967 / mAP50-95 0.890，test 与 val 一致（无过拟合裂缝）
- **核心结论：mAP50-95 +0.175 证明标注框贴合度直接转化为定位精度**——共识+仲裁+人工流程的价值量化
- 口径警告：test 集同出这套标注流程（同分布自洽验收）；跨集泛化需独立帧再验
