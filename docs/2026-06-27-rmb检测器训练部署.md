## 1. 背景与目标

第五套人民币 6 面额(1/5/10/20/50/100 元)目标检测。原始 `rmb_yolo` 数据集严重偏差(87% 单目标、bbox 中位占画面 45%、白底同质化), 直接训练在真实场景(柜台/桌面/手持)泛化差。改用 **Copy-Paste 合成** 针对性补: 小目标、多目标、复杂背景、面额均衡。

**为什么全合成 + 同分布 val/test**: v9 用 rmb_yolo 白底验证集评估"场景化"模型, 导致训练分布内 mAP50=0.995 但 rmb_yolo val 暴跌 0.379(domain shift 假象)。v10 val/test 全部合成、与 train 同分布, 公平反映模型学习能力; 真实场景泛化需另建真实测试集。

## 2. 数据集 rmb_synth_v10

| split | 图像数 | 用途 |
|-------|--------|------|
| train | 4000 | 训练 |
| val | 500 | 验证(与 train 同分布) |
| test | 500 | 测试(与 train 同分布) |

- **6 类**: 0=1yuan, 1=5yuan, 2=10yuan, 3=20yuan, 4=50yuan, 5=100yuan
- **面额均衡**: 每面额 1620-1723 bbox
- **bbox 面积中位 7.21%**: 柜台/桌面俯视的中等小目标尺度
- **每图 2-3 张钞票**(均 2.48): 多目标散落场景
- YOLO 标准布局: `images/{train,val,test}/*.jpg` + `labels/{train,val,test}/*.txt`
- 配置: `data_abs.yaml`(`path` 绝对路径, 迁移服务器后改 `path` 即可)

**已知限制**: ① bbox 基于 YOLOE-seg alpha mask, 残余 ±5-15% 边缘误差(IoU>0.8, 对训练影响小); ② 小面额(1/5/10 元)前景池各仅 ~110 张, 外观重复(靠旋转/缩放/光照随机化); ③ 合成规律性(每图恰 2-3 张), 合成高分不完全等同真实场景能力。

## 3. 合成 Pipeline(复现)

```
rmb_yolo (4821图,带bbox标注)
   │  rmb_cut_from (YOLOE-seg 按bbox抠透明PNG)
   ▼
notes_cut (2754 张透明钞票, 按面额分目录) ─────┐
                                               │
COCO instances + 真实照片                      │  synth_compose (Copy-Paste)
   │  synth_gather_coco + synth_resize_bg      │  (缩放/旋转±25°/光照匹配)
   ▼                                           ▼
backgrounds_960 (6137 张 960×960背景) ──→ rmb_synth (5000合成图)
                                               │  synth_build_splits (随机80/10/10)
                                               ▼
                                    rmb_synth_v10_split (train4000/val500/test500)
```

**两个 venv**: 合成/划分/裁剪用轻量栈(typer/pydantic/httpx/PIL); YOLOE-seg 抠图用 ultralytics/torch 栈(本项目 `.venv`)。

**关键参数(已调优)**: Copy-Paste `scales=[0.24..0.74]`(bbox 中位 ~7%); 旋转 ±25°; bbox 基于 alpha 不透明区域(紧贴钞票, 非画布外接矩形)。

### sgcc0 环境搭建(最小集, 不依赖整个 jxl)

sgcc0 无 ultralytics。建独立 venv, 只装训练必需(避免 jcx/jvi 本地 file 依赖):
```bash
ssh sgcc0 'cd ~/ws/sgcc/money/search && uv venv .venv --python 3.12 && uv pip install --python .venv ultralytics typer loguru'
# → torch 2.12.1+cu130, ultralytics 8.4.80, CUDA True, RTX 4090
```

数据/权重/训练脚本传送(scp):
```bash
tar cf /tmp/rmb_synth_v10_split.tar assets/rmb_synth_v10_split/   # 1.1G, jpg 不可压用 tar cf
scp /tmp/rmb_synth_v10_split.tar yolo26n.pt src/jxl/bin/yolo_train.py sgcc0:~/ws/sgcc/money/search/
# 解压后改 data_abs.yaml 的 path → /home/jiang/ws/sgcc/money/search/assets/rmb_synth_v10_split
```

⚠️ `yolo_train.py` 的 shebang 是本地 jxl venv 路径, 远程用 `.venv/bin/python yolo_train.py` 显式调用(shebang 被忽略)。

### 训练执行(setsid 独立运行)

用 `setsid` 而非 `nohup`：采纳 person 训练教训（nohup 在 ssh 断时曾被 SIGHUP 杀，setsid 彻底脱离会话才稳定）。通用根因/解法见 kb `20260710-yolo-training-deploy-sop.md` §1，另见 [[2026-06-27-person模型训练部署]]。
```bash
ssh sgcc0 'cd ~/ws/sgcc/money/search && setsid .venv/bin/python yolo_train.py \
  assets/rmb_synth_v10_split/data_abs.yaml --model yolo26n.pt --epochs 200 \
  --imgsz 640 --batch 32 --device 0 --project runs/detect \
  --name rmb_synth_v10_yolo26n --patience 50 --exist-ok \
  > train.log 2>&1 < /dev/null & disown'
```
**resume**: `--model .../last.pt --resume --exist-ok`（resume 必须传 last.pt 的通用原因见 kb `20260710-yolo-training-deploy-sop.md` §2）。

⚠️ 输出路径因 project 参数出现 `runs/detect/runs/detect/rmb_synth_v10_yolo26n`(双层, ultralytics 相对 project 拼到 SETTINGS runs_dir), best.pt 在该目录 `weights/` 下。project 应传绝对路径根治（通用说明见 kb `20260710-yolo-training-deploy-sop.md` §6）。

## 6. 训练结果

**训练**: 200 epoch, 0.813 小时(49min, RTX 4090), best = epoch 192, patience=50 未触发早停(跑满)。

### 指标轨迹(val, epoch 关键点)

| epoch | mAP50 | mAP50-95 | P | R |
|-------|-------|----------|---|---|
| 1 | 0.145 | 0.103 | 0.217 | 0.182 |
| 25 | 0.839 | 0.652 | 0.847 | 0.763 |
| 50 | 0.887 | 0.737 | 0.889 | 0.819 |
| 100 | 0.923 | 0.806 | 0.936 | 0.859 |
| 150 | 0.922 | 0.825 | 0.943 | 0.873 |
| **192(best)** | **0.927** | **0.834** | 0.972 | 0.867 |
| 200 | 0.926 | 0.832 | 0.966 | 0.871 |

mAP50 在 epoch 100 后基本进入平台(0.923→0.927); mAP50-95 持续小幅爬升至 epoch 192 的 0.834 后微回落, 已近收敛平台。（收敛判读见 kb `20260710-map-metric-interpretation.md`。）

| 评估集 | Precision | Recall | mAP50 | mAP50-95 |
|--------|-----------|--------|-------|----------|
| 合成 val(训练时, best=ep192) | 0.972 | 0.867 | 0.927 | 0.834 |
| **合成 test(独立评估, 500图)** | **0.962** | **0.905** | **0.942** | **0.843** |
| 真实场景照片 | — | — | — | **必须另建真实测试集才能定论** |

test 与 val 一致(test mAP50 0.942 ≈ val 0.927) → 同分布泛化良好, 无过拟合。（泛化判据见 kb `20260710-map-metric-interpretation.md`。）

**test per-class**:

| 面额 | P | R | mAP50 | mAP50-95 | 备注 |
|------|---|---|-------|----------|------|
| 1yuan | 0.951 | 0.932 | 0.953 | 0.837 | |
| 5yuan | 0.964 | 0.876 | 0.931 | 0.856 | |
| 10yuan | 0.967 | 0.820 | 0.882 | 0.807 | **最弱**(小面额前景池仅 ~110 张, 外观重复) |
| 20yuan | 0.983 | 0.932 | 0.958 | 0.847 | |
| 50yuan | 0.960 | 0.954 | 0.964 | 0.875 | |
| 100yuan | 0.947 | 0.918 | 0.963 | 0.838 | |

**推理速度**: 0.9ms/图(4090, fused 122 layers, 2.38M params)。best.pt 5.2MB。

**本次指标要点**（通用定义见 kb）: mAP50-95=0.843 高于 person(0.720)——主因合成数据 bbox 精确、场景可控；10 元最弱(mAP50 0.882)为已知限制②, 可用 `rmb_gen_variants`(可灵变体)补充。
