# Datasets 现状、构建规则与清理清单（2026-07-09）

> person 检测数据集全景：datasets/ 多来源池构建规则+步骤、现状盘点、临时/过时/备份数据清理清单。

## 1. datasets/ 构建规则（多来源池 + symlink 组合）

**核心思想**：数据集按**来源/性质**独立成集（`datasets/<name>/images+labels`，YOLO 格式），训练时按 experiment 配置**选择性 symlink 组合**，不同实验不同样本组合。

**三要素**：
1. **datasets/**：多来源样本池（原始来源 + 自动标注集），每集统一 `images/+labels/`（YOLO cls=0 person）
2. **experiments/*.toml**：实验配置（列样本集组合 + split 比例），配置即实验记录
3. **link_samples**（`src/jxl/bin/link_samples.py`）：读 toml → 前缀 symlink（`{dataset}_{original}`，全局唯一+可追溯）→ `experiment/<name>/` → `jxl_split` → `yolo_train`

**为什么**：不同训练目标需不同样本组合（如"基线" vs "非站立增强"），symlink 组合避免重复存储 + 可复现。

## 2. 构建步骤（how-to）

### 2.1 收录原始来源（→ datasets/，转 YOLO）
```bash
# COCO/MOT/CrowdHuman 原始 → datasets/，用转换工具产 YOLO
coco_to_yolo <coco_json> <images> datasets/COCO
mot_to_yolo <mot_gt> <images> datasets/MOT17
crowdhuman_to_yolo <odgt> <images> datasets/CrowdHuman
```

### 2.2 自动标注集（det_mine 多模型）
```bash
# person.pt + YOLOE + GDINO + RF-DETR 多模型共识 + 争议分 cascade
det_mine <frames> <out> --target person --validators yoloe,gdino,rfdetr
# → L1（多模型共识）+ review（高争议）+ L0（全一致 drop）
```

### 2.3 在线 grounding 复检（doubao_relabel，review 子集）
```bash
# review 高争议 → 豆包 vision grounding 裁判
doubao_relabel <review_manifest> <review_imgs> <out_labels> --cfg <doubao.json>
```

### 2.4 配置 + 组合训练
```bash
# experiment toml（列样本集）
cat experiments/non-standing-boost.toml
# → name + datasets + split

# link_samples 组合 → jxl_split → 训练
link_samples experiments/<exp>.toml experiment/<exp>/
jxl_split experiment/<exp>/ dataset/<exp>/ -r 8 1 1
yolo_train dataset/<exp>/data.yaml --model yolo26n.pt
```

| 清理类别 | 节省 |
|---------|------|
| 临时/验证 | ~5M |
| 中间产出（sgcc-detmine + CrowdHuman detmine/zip）| ~20G |
| 备份（sgcc-yoloe-bak + samples-old-backup + dataset-old）| ~18G |
| 过时历史（samples_core/dedup/reid + embeddings）| ~14G |
| **合计** | **~52G** |

数据盘当前 1.4T 可用（63% 用），清理 52G 后 ~1.45T 可用——非紧迫，但保持整洁。
