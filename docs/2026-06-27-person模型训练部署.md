# Person 检测模型训练与部署存档（2026-06-27）

> YOLO26n 单类 person 检测器: sgcc 监控样本 + MOT17/MOT20 固定 CCTV + COCO 通用网图混合训练, 200 epoch, 部署 sgcc0→本地 /opt/howell/iap。

## 1. 背景与目标

sgcc person 监控样本(14284 图)场景单一、人重复、背景同质, 检测器泛化不足。补充固定 CCTV(MOT17/20) + 通用多样(COCO)数据, 混合训练 nano 模型, 部署到监控产品。

**最终成果**: mAP50=**0.956**, mAP50-95=**0.720**, 推理 0.5ms/图(4090), 已导出 ONNX 部署。

## 2. 数据集构成与处理

### 数据来源

| 源 | 原始规模 | 处理后 | 处理 |
|----|---------|-------|------|
| sgcc 监控 | 14284 图 | 14284 | 原样本(去重另见 [[2026-06-25-数据去重存档]]) |
| MOT17 | 5316 帧 | **1064** | 下载→mot_to_yolo→frame_sample stride=5 |
| MOT20 | 8931 帧 | **1787** | 同 MOT17(超密集, 50-230 人/帧) |
| COCO Person | 66808 图 | **7840** | 下载→coco_to_yolo→Phase1 过滤→core-set 采样 |
| **合计 samples** | — | **24975** | 合并进 samples/ |

### MOT17/MOT20 处理

- **下载**: HF mirror `Lekim89/MOT17`、`Lekim89/MOT20`(motchallenge.net / GitHub SSL 死, hf-mirror.com 通)
- **转换**: `mot_to_yolo`(MOT gt `frame,id,x,y,w,h,conf,class,vis` → YOLO 归一化; 筛 class 1 pedestrian + 7 static person; 边界 clamp)
- **去冗余**: `frame_sample --stride 5`(连续视频相邻帧相似, 时序下采样 -80%)
- 只取 FRCNN 检测器变体(MOT17 DPM/SDP 图片相同, 去重); MOT20 序列名无后缀

### COCO Person 处理(两阶段减量 66808→7840)

**Phase1 过滤**(去低价值): `coco_filter` 读 COCO json
- 去小目标框(短边 <32px, 41% 远景小人)
- 去密集图(person >8, 11306 图)
- 去 iscrowd=1(5439 人群聚合框)
- 去全小人图(过滤后无 medium+large person)
- 66808 → 49857 图

**Phase2 core-set 采样**(保多样): `yolo_coreset`
- DINOv2 图级 embedding(384d) + k-means(target 8000) + 每簇选离 centroid 最近代表
- 49857 → **7840 图**(1.3G), 无小框无密集, 场景/姿态多样

### 划分(8:1:1)

`jxl_split`(darknet_split, symlink 不复制):
- train **19980** / val **2497** / test **2498**
- data.yaml: `path: .../dataset`, `train: train/images`, `val: val/images`, `names: {0: person}`

## 3. 训练配置

| 项 | 值 |
|----|-----|
| 训练机 | sgcc0(ssh sgcc0, RTX 4090 24G) |
| 模型 | yolo26n.pt(nano, 2.6M 参数, 预训练) |
| epochs | 200(patience=0, 不早停跑满) |
| imgsz | 640 |
| batch | -1(AutoBatch=32, 13.7G/23.5G) |
| optimizer | auto(MuSGD lr=0.01) |
| device | 0(workers=8) |
| 工具 | `yolo_train data.yaml --model yolo26n.pt --epochs 200 --patience 0` |

### sgcc0 环境搭建要点

- sgcc0 无 .venv, **直连 GitHub 不可达**(clip @ git+github 卡 uv sync)
- 解决: `uv pip install --python .venv/bin/python` 手动装核心包(绕 clip), jcx/jvi 本地路径依赖先 rsync, jxl `--no-deps -e` 装
- VPN 带宽差(<0.4MB/s), .venv 9.5G 不能 rsync, 改 sgcc0 本地 uv pip install(走 PyPI)
- yolo26n.pt 权重本地 rsync(避免 ultralytics 自动下 GitHub 失败)
- sgcc0 配置 proxychains(备, 加速 GitHub/外网, 关联 [[sgcc0-proxychains]])

### 训练执行(独立运行)

`setsid` 启动(比 nohup 更彻底脱离 ssh, 避免 SIGHUP 终止):
```bash
ssh sgcc0 'setsid .../python -m jxl.bin.yolo_train data.yaml --model .../yolo26n.pt \
  --epochs 200 --patience 0 --device 0 --name person_nano_200 --project .../runs \
  >> train.log 2>&1 < /dev/null &'
```

**踩坑**: 首次 nohup+disown 在 epoch 53 被 SIGHUP 异常终止(ssh 断)。改 setsid 后稳定跑完。

**resume**: `--model last.pt --resume --exist-ok`(从 epoch 54 续; 注: --model 必须指向 last.pt, 传 yolo26n.pt 会从头)。

## 4. 训练结果

### 指标轨迹(epoch 关键点)

| epoch | mAP50 | mAP50-95 |
|-------|-------|----------|
| 1 | 0.852 | 0.511 |
| 50 | 0.943 | 0.677 |
| 100 | 0.945 | 0.690 |
| 150 | 0.952 | 0.705 |
| 200(best) | **0.956** | **0.720** |

后期 mAP50-95 仍小步爬升(0.705→0.720), 已近收敛平台。

### 最终(best.pt)

| 指标 | val(train 时) | **test(独立评估)** |
|------|--------------|------------------|
| mAP50 | 0.956 | **0.9545** |
| mAP50-95 | 0.720 | **0.7203** |
| Precision | 0.960 | 0.9563 |
| Recall | 0.894 | 0.8892 |

**test 与 val 几乎一致**(差 <0.005) → 泛化良好, 无过拟合, 结果可信。

**指标解读**:
- mAP50 0.956: 人几乎全找到(松标准 IoU≥0.5)
- mAP50-95 0.720: 框定位精度良好(严格 IoU 0.5~0.95 平均); 拉低主因: 小目标/遮挡/MOT20 密集
- P 0.96: 误报仅 4%(报出的几乎都是人)
- R 0.894: 漏报约 11%(漏的为小目标/遮挡/密集难例, 正常监控距离基本不漏)

### nano vs small 评估(搜索结论 + 实证)

官方 COCO 80 类: yolo11n 39.5 → yolo11s 44.7(+5 mAP)。单类 person 差距更小。20k 数据对 nano 充分(甚至过参), small 易过拟合。**实证 nano mAP50-95=0.720 已良好, 没必要训 small**(边际 +0.03~0.05, 部署成本翻倍)。

## 8. 复现要点

1. 数据: sgcc samples + dates/{MOT17,MOT20,COCO}(各源独立 YOLO, 已 frame_sample/core-set)
2. 合并 samples → `jxl_split samples dataset -r 8 1 1`
3. 训练: `yolo_train dataset/data.yaml --model yolo26n.pt --epochs 200 --patience 0`
4. 评估: `yolo val model=best.pt data=data.yaml split=test`
5. 导出: `YOLO('best.pt').export(format='onnx', simplify=True)`
6. 部署: rsync best.pt + best.onnx → /opt/howell/iap/v0.9/ias/model/

> 训练在 sgcc0(RTX 4090) 约 5~6h(200 epoch, ~1.7min/epoch)。setsid 独立运行, 本机断开不影响。
