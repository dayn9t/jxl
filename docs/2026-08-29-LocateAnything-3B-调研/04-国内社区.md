## 一、调研对象与官方基准事实（用于交叉验证的锚点）

LocateAnything-3B 是 NVIDIA 开源的 3B 参数视觉定位 VLM（Eagle VLM 系列），官方发布日期为 **2026-05-26**（GitHub / Hugging Face / Demo / 项目网页 / 技术报告五渠道同日，来源：[ModelScope 模型卡](https://modelscope.cn/models/nv-community/LocateAnything-3B)）。

官方模型卡关键数字（国内两个镜像源逐字核对一致）：

| 项目 | 官方口径 | 来源 |
|---|---|---|
| 参数量 | 3B（30 亿） | [ModelScope 模型卡](https://modelscope.cn/models/nv-community/LocateAnything-3B)、[GitCode 中文镜像](https://ai.gitcode.com/hf_mirrors/nvidia/LocateAnything-3B) |
| 训练数据 | 12M unique images / 138M+ queries / 785M bounding boxes | 同上 |
| 架构 | MoonViT 视觉编码器 + Qwen2.5-3B-Instruct + MLP projector，原生分辨率 VLM | 同上 |
| 吞吐 | Parallel Box Decoding (PBD) 「up to 2.5× higher throughput」 | 同上 |
| 第三方组件许可 | Qwen2.5-3B-Instruct（Qwen Research License）、MoonViT-SO-400M（MIT） | 同上 |
| 模型许可 | NVIDIA License for non-commercial use——**仅限学术与非营利研究，禁止商业使用** | 同上 |
| 伪标工具 | 标注由 Qwen3-VL、Molmo、SAM 3、Rex-Omni 辅助生成 + 自动后验证 | 同上 |
| 评测规模 | 约 48K 张图（box 评测）/ 35K 张图（point 评测）；效率以单卡 H100、batch 1 的 BPS（boxes per second）计 | 同上 |
| 分辨率/上下文 | 生产图像分辨率最高 2.5K；prompt 最长 24K tokens；推理最多生成 8192 新 token | 同上 |
| 产品化 | 已集成进 Nemotron 3 Nano Omni（grounding / GUI 理解 / 多模态智能体） | 同上 |

GitCode 中文镜像独有补充内容：`batch_infer.py` + `la_flash`（FlashAttention-varlen 稀疏范围执行器）批量推理；A100 4K 街景图 `query=vehicle`、`batch_size=4`、混合 MTP 推理实测：`sdpa` 后端 8.2600 秒 / 峰值预留内存 35.12 GB，`la_flash` 后端 8.0314 秒 / 11.71 GB（来源：[GitCode 镜像页](https://ai.gitcode.com/hf_mirrors/nvidia/LocateAnything-3B)）。
