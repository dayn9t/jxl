# 数据去重存档（2026-06-25）

> sgcc person 场景：检测样本 + 分类人样本的减量去重 pipeline。

## 1. 背景与目标

| 数据集 | 位置 | 规模 | 用途 | 问题 |
|--------|------|------|------|------|
| samples | `/home/jiang/ws/sgcc/person/samples` | 14284 图（带 YOLO bbox） | 检测训练 | 监控抽帧，背景相同 + 同人多次 + 相邻帧重复 |
| person_crops | `/home/jiang/ws/sgcc/person_crops` | 39370 person crop | 分类训练（年龄/性别/身份） | 监控固定摄像头，同一人大批量重复 |

**目标**：降低训练负担 + 避免重复样本导致的过拟合。

## 2. 关键挑战：背景主导

监控场景**背景占图大部分且完全相同，只有 person 不同**。整图去重方法在此场景**失效**：

- **pHash（整图）**：背景相同 → 哈希位大多相同 → 不同 person 的图 Hamming 距离小 → **误删**带不同 person 的好样本。
- **CLIP/DINOv2 整图 embedding**：背景像素占多数 → embedding 被背景主导 → 不同 person 的图余弦相似度仍 >0.95 → **同样误删**。

**解法：前景感知** —— 把去重单位从「整图」改为「person crop」（前景），背景被忽略，只看 person 是否同姿态/同人。

## 3. 研究与方案决策

用 Workflow 4 路并行 web 研究（2024-2026 最新技术）：近似重复去重 / 核心集选择 / person Re-ID / 数据蒸馏。

### 关键发现：DINOv2 做不了身份聚类

实测 DINOv2 对 39370 person crop 做 HDBSCAN → **聚成 1 大簇（39361/39370）**。DINOv2 是通用语义模型（非 Re-ID），区分不了人身份，只能区分姿态。

→ 身份级同人合并需专门 **Re-ID 模型（OSNet body / ArcFace 人脸）**，DINOv2 不支持。

### 采用方案：研究 Stage 1+2（可靠，不依赖身份）

| 阶段 | 技术 | 作用 |
|------|------|------|
| Stage 1 | **SemDeDup**（Faiss 余弦 ≥0.95 + 并查集） | 去近重复姿态/角度 |
| Stage 2 | **k-means core-set**（DINOv2 embedding） | 选姿态/场景多样代表，压到目标数 |

身份级 Re-ID（Stage 3）留作**可选增强**（需装 torchreid/用 insightface）。

## 4. 实现（jxl bin 工具）

| 工具 | 作用 |
|------|------|
| `src/jxl/bin/person_embed.py` | DINOv2（HF `facebook/dinov2-small`, 384d）embedding 提取，L2 归一化。走 HuggingFace 绕开 GitHub release 限速。 |
| `src/jxl/bin/person_dedup.py` | 场景 B：SemDeDup + k-means core-set → 每姿态多样代表 + `sem_cluster_map.npy`（供场景 A） |
| `src/jxl/bin/samples_dedup.py` | 场景 A：整图 person 姿态指纹去重（图 = person crop 的 SemDeDup 簇集合），相同指纹留 1 |

## 5. 结果

| 场景 | 输入 | 输出 | 减量 |
|------|------|------|------|
| **B 分类**（person crop） | 39370 | **7831**（SemDeDup 32398 → core-set 7831） | **-80%** |
| **A 检测**（整图） | 14284 | **13299**（姿态指纹去同姿态重复） | -7% |

**SemDeDup 实测**：32398 簇，最大簇 487（= 同人同姿态多次被合并），单元素簇 30719（person 姿态多样，近重复少）。
**core-set 抽样**：跨 vip2/top 多摄像头/时间，姿态多样 ✓。

**产物**：
- `/home/jiang/ws/sgcc/person_crops_dedup/`（7831 代表 crop + `sem_cluster_map.npy` + `sem_cluster_files.txt`）
- `/home/jiang/ws/sgcc/person/samples_dedup/`（13299 整图 + labels）
- `/home/jiang/ws/sgcc/person/embeddings.npy`（39370×384）+ `embeddings.txt`

## 6. 环境修复（uv nvidia namespace bug）

`uv add faiss-cpu` 触发 uv 重算依赖树，把 torch 的 CUDA 运行时依赖（`nvidia-cusparselt-cu12` 等）的 `.so` 从 venv 丢失（uv 对 nvidia namespace 包的 link 失效）。

**修复**：从 `~/.cache/uv/archive-v0/*/nvidia/*/lib/` 把所有 nvidia 子包 `.so` 补全到 `.venv/lib/python3.12/site-packages/nvidia/*/lib/`，torch 无需 LD_LIBRARY_PATH 即可 `cuda True`。

显式加依赖：`nvidia-cusparselt-cu12`（避免 uv 再优化掉）。

## 7. 用法

```bash
cd /home/jiang/py/jxl

# 1. 提 DINOv2 embedding（GPU, ~2min/39370）
.venv/bin/python -m jxl.bin.person_embed \
  /home/jiang/ws/sgcc/person_crops \
  /home/jiang/ws/sgcc/person/embeddings.npy

# 2. 场景 B: person crop 去重（SemDeDup + core-set, target 8000）
.venv/bin/python -m jxl.bin.person_dedup \
  /home/jiang/ws/sgcc/person/embeddings.npy \
  /home/jiang/ws/sgcc/person_crops \
  /home/jiang/ws/sgcc/person_crops_dedup --target 8000

# 3. 场景 A: 整图姿态指纹去重
.venv/bin/python -m jxl.bin.samples_dedup \
  /home/jiang/ws/sgcc/person_crops_dedup \
  /home/jiang/ws/sgcc/person/samples \
  /home/jiang/ws/sgcc/person/samples_dedup
```

> 调参：`person_dedup --sem-threshold 0.95`（SemDeDup 余弦阈值，降则去更多近重复）、`--target 8000`（core-set 目标数）。

## 8. 审核与后续

**审核**：ruff 核心修正（B905 zip strict）；剩余为项目 bin 脚本既有风格噪声（D 中文 docstring / S101 / E501 / PLR0913 typer，img_label/sam_label 同样）。

**后续可选**：
- **身份级 Re-ID 合并**：装 `torchreid`（OSNet body）或用 `insightface`（ArcFace 人脸），对 crop 提 Re-ID embedding → HDBSCAN 同人聚类 → 每身份留 N 代表。监控固定摄像头场景收益最大。
- **从源头减重**：仍在抽帧流时优先用 ultralytics 内置 **BoT-SORT** 产稳定 track ID，按 track 聚合减少重复 crop。
- **分类器标签**：减量后的 `person_crops_dedup`（7831）可供年龄/性别/身份分类器训练，标签来源待定（人工/age-gender 模型打标/已有数据）。
