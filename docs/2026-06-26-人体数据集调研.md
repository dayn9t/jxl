## 2. Google Open Images person 子集（你提到的）

Google Open Images V7 含 **Person** 类（~170k 标注），程序化拉取：
```python
import fiftyone as fo
ds = fo.zoo.load_zoo_dataset(
    "open-images-v7", split="train",
    label_types="detections", classes=["Person"],
)
```
- 工具：`fiftyone`（最便）或 `OIDv6 Toolkit` 或 `google/openimages`
- 质量：自动标注（machine-annotated），不如人工集精，但量大免费

## 4. 网络/SSL 注意（本次实测）

- **motchallenge.net / GitHub release / Google Drive**：SSL_ERROR_SYSCALL（断连），直链不可行
- **huggingface.co API**：SSL 断连
- **hf-mirror.com**（国内镜像）：**通**，可绕 SSL（OSNet 权重 + MOT17 mirror 实测可下）
- **fiftyone**：走 cocodataset.org / Open Images GCS，需测

**建议**：优先 `fiftyone`（COCO/Open Images）或 `hf-mirror.com`（CrowdHuman/MOT17 mirror），避开直链 motchallenge.net/GitHub release。
