## 2. 机制设计

### 2.1 削减算法（簇内近重复优先，置信度次级）

```
1. dino 嵌入聚类（复用 dedup_sem 基建，cos≥0.90 簇——比入集去重的 0.95 更宽，
   覆盖「相似但不全同」的冗余带）
2. 簇内排序键：主=簇内最大近邻相似度（近重复优先，SemDeDup 式）；
   次=已训模型对该样本 conf（用户思想保留位：同近重复度时删高置信）
3. 保留：每簇代表（簇中心最近）+ 全部低置信成员（<0.5）+ 孤立簇（成员=1）永不删
4. 削减档位：10% / 20% / 30% 阶梯（VPS 警告 30% 以上风险陡增，不做 50%）
```

### 2.2 隔离池（holding pool，用户裁决：不丢弃）

每条被隔离样本带元数据：`{cluster_id, 近邻相似度, 当轮模型 conf, 删除轮次/比例档,
历次回流评测结果}`。物理上=独立目录（对等路径原则），逻辑上=训练集的可逆外挂。

### 2.3 回流触发（每轮新模型训完自动跑）

- 新模型在隔离池上评测（检出/分类表现）
- **回流判据**：池样本表现回退（检出丢失或 conf 下降 >0.2）→ 加回训练集（带回流标记）
- **震荡熔断**：同一样本删除→回流→再删 ≤2 次，第三次起永久保留

### 2.4 证据记录（假设-实证原则的落地）

实验（SGCC 上跑，SHTM 复用结论）：

| 组 | 数据 | 测量 |
|---|---|---|
| 基线 | v3 全量 13,788（已有 test 0.8855，不重训） | — |
| 实验 ×3 | 削减 10/20/30% 各重训（sgcc0 同配方，~3h/次） | test mAP、隔离池回流率、train/val loss gap、训练时长 |

判决表写入本文件 §4：支撑（mAP 不降+回流率低）→ 机制入循环默认开 20%；
反驳（任一档降 >1pp）→ 降档或改为纯近重复模式；gap 收窄=过拟合对症证据。

## 4. 证据记录（T5 消融实测 2026-09-10，SGCC dataset_v3，test 干净口径）

| 档位 | test mAP50-95 | Δ vs 0.8855 | 隔离池回流率 | 时长省 | 判定 |
|---|---|---|---|---|---|
| p10 (-10%) | 0.8828 | -0.27pp | 7% (75/1103) | ~10% | ✅ 支撑 |
| p20 (-20%) | 0.8829 | -0.26pp | 4% (91/2206) | ~20% | ✅ 支撑（甜点档） |
| p30 (-30%) | 0.8808 | -0.47pp | 4% (141/3309) | ~30% | ✅ 支撑 |

**结论（假设-实证循环判决）**：三档全部低于 1pp 反驳阈值——**簇内近重复削减假设支撑成立**。
- p10 与 p20 损耗相同（-0.27≈-0.26pp），p20 省时翻倍 → **20% 为甜点档**；p30 损耗仍可接受
- 回流率 4-7%（新模型对被删样本 93-96% 仍表现良好）——删除正确性的独立验证
- val 口径同步验证：p10 0.879 / p20 0.877 / p30 0.869（基线 0.8801），趋势一致
