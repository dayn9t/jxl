## 2. 发现：L0 弱共识放行毒标注（部署暂停的根本原因）

**因果链（全部实锤）**：
```
crop640 候选按"有前景"筛选(不区分人/物) → 柜员离场时段玩具/包被当前景帧
→ gdino(conf 0.34) + la(conf 恒 1.0) 在玩具位置重叠 → consensus=2 弱共识过审 L0
→ yoloe/rfdetr 的正确反对被忽略(一致≠正确) → 毒框直入训练集无仲裁
```

**量化**：
- 毒标注 1,508 框 / 1,501 帧：cam1 红色毛绒玩具 1,480（区域 [533,261]~[640,436]+10px）
  + cam2 深色包/帽 28（VLM 判 object）
- train/val/test 各 ~21% cam1 帧污染（1,189/164/148）→ **test mAP50-95 0.895 虚高**
- 双模型差集对比：only_new 16,352 帧中 85.7% = 玩具固定位置误报（14,315 帧）、
  3.6% cam2 底部物（608 帧）；det 47.1%(新) vs 14.0%(现网) 的差异主要由毒标注贡献
- only_prod 74 帧 = 现网把 cam2 红色小马玩具误检为人（conf~0.26），新模型正确拒绝
- 毒框层归属：L0/validators_all 1,478 + L1/batch 23 + 仲裁 0 + **人工 VLabel 层 0**
- L0 放行通道宽度：10,437 帧采信中 **16.3%（1,698 帧）**的框仅被弱验证器支持、被强验证器反对
- 删后 1,501 帧全部转空标负样本（本就是无人帧被物误标）——**图片一张不删**

## 3. 审计方法（三层法，成本结构关键）

```
A 几何签名聚类: DBSCAN(按 cam 分组! eps=30, 特征=中心xy+wh) 全量 18,999 框 → 20 簇
B 簇代表 VLM 定性: 每簇抽 3 不同日期帧 → doubao 判 person/object/mixed
   （60 次调用定性 18,999 框，成本↓99.7%）
C mixed 漏斗: 现网模型支持性交叉(3,136→373 高危, ↓88%) → 残余逐帧 VLM(28 object/345 person)
终审: VLabel 人工审核项目
```

教训：**柜员常驻位与静态物的几何签名几乎相同**（位置集中/跨日期/尺寸稳）——几何只筛候选，
语义定性必须 VLM/人；判据用区域外接矩形全扫（DBSCAN 簇成员会漏边缘散点，实测 +20 框）。

## 6. ①②层架构裁决（2026-09-08 阈值数据反演定稿）

用户质疑「①层会否再犯一致性错误、①②是否合并」→ 阈值分析（`research/2026-09-08-共识分层
阈值数据分析.md`，1,508 毒框 GT 全匹配反演）裁决：

- **任何共识闸门（含 4/4 全一致）都有非零毒框残留**（k≥4 残留 1/14,079；strong≥2 残留 6）；
  现行 k=2 闸门拦截率仅 0.4%——事故根因的量化确认
- **残留框全部落在静态物位置** → 共识签名漏掉的，位置签名能零成本兜住
- **最终架构（取代早期"全覆盖深度审计"合并方案）**：
  ```
  ① 强共识层（闸门 k≥2 ∧ strong≥1：拦截 97.3%/误伤 3.1%；保守档 k≥3）
     + ②-lite 位置聚类卫兵（DBSCAN <1s CPU、0 VLM，常驻①出口——免 VLM 成立，免位置扫描不成立）
  ② 异常签名 → 漏斗交叉(压缩 88.1%，真正可靠机制) → 残余 VLM 逐帧
  ③ VLM 弃权/翻转 + 终审
  端到端: 残留 0/1,508；VLM 428 次(覆盖 2.3%)；人工 2-4 人时
  ```
- **方法警告**：VLM 簇代表 n=3 抽样对 mixed 簇漏检率 88-96%（本次命中属运气）——
  n=3 只可用于全一致 object 快判，person 判定必须走漏斗；帧级争议分对一致性地错零分辨力
- **限定**：GT 毒型单一（静态物），镜面/海报类毒型不外推，①保留 1% 抽查保险；
  cam2 28 框 GT 有 VLM 自证循环；阈值场景耦合换场景需重标定
