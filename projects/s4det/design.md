## 0. 目标与不做清单

**目标**：为 s4 事件域训练统一目标检测器（单模型，ultralytics YOLO），检出 mobile/road/scene 三域全部事件相关目标（两级类目表），供判定层（LLM/judge）消费；以 jxl+vlabel 共识标注流水线建立数据飞轮。

**不做（v1）**：
- ET 4/5/8/9/10（店招牌归 s4-shop 域已有检测线；突发情况无固定目标）。**「全部事件目标被检测覆盖」的口径** = 每类事件目标至少被一条检测线覆盖（s4det 或既有 sign.pt）——店招牌由 shop 域检测线覆盖，非从事件目标中删除；ET4 道路设施损坏的目标即 road 部件类（s4det 覆盖）；ET10 突发情况无封闭类集，闭集检测器原理上不可定义，由判定层兜底
- 状态/关系类不作为检测类（违规充电/占道经营等只标**载体**，违规性留判定层）
- 实例分割 / 旋转框 / amodal 全框（v1 全部 bbox 可见框）
- scene 203 全动态 prompt 不逐条穷举（词频并入形态词典与类目佐证）
- 检测器接入 s4 事件管线的推理服务化（后续单独立项）

## 2. 类目体系（两级类目表）

- **叶类**（检测器标签）：视觉内聚、EN 短名；细分硬条件 = 视觉可辨 ∧ 样本 ≥50-100 张（不满足并回母类入隔离台账待数据长成再拆）；纯语义不可视区分不拆（红线）。
- **粗类映射**：叶类 → 事件粗类（EventType/部件/判定用途）many-to-one 查表，单一数据源 `taxonomy.md`（待建）。
- **v1 产出流程**：桌面草案（盘点 §7，~35 叶类候选）→ 按粗类抓图 → DINOv3 embedding → Faiss 聚类 → 簇代表网格审图 → 人工命名/合并/剪枝 → **用户审批冻结**。
- **形态词典**：每叶类形态要点 + 难例样本图，随飞轮演化（skill j-consensus-labeling ⑪；scene 203 词频表是第一份输入）。

## 2b. 固定目标哨兵路径（2026-09-25 用户口述决策，与检测器并行）

**分派总则**：动态可移动、形态确定的目标 → 检测器主路径（现行 P3-P5）；静止固定位置、形态/边界不确定的目标 → **GPS+视频+VLM 哨兵路径**（不硬塞检测器）。判定细则与逐类归属见 taxonomy.md facility 节。

**哨兵路径机制**：目标 GPS 位置/区间缩搜索范围 → 附近短视频（~5s，1fps）→ VLM 定位目标/筛图/生成描述存档 → 前后状态对比（褪色/涂鸦/破损/移位）。

- **首批适用**：billboard（检测器不胜任——无边界、内容自由）；sculpture（倾向此路径，批 2 样本验证检测器胜任性后终定）。
- **与既有机制同构**：road 部件三态（发现/异常/消失）、scene 203 五连拍——本路径是把「固定目标哨兵」模式升为与检测器并行的正式路径；jxl 侧能力（vlm_pool/GPS 过滤/video_keyframe/状态比对）均有既有件。
- **立项时点**：facility 批次（批 2 后的 road 打框批）时正式实施；批 2（mobile 17 类）不受影响。
- **评估口径预警**：哨兵路径目标**不适用 mAP**——评估口径=状态对比准确率/描述质量/定位可用率（EVAL-BENCHMARKS 已记 T10 预留）。

## 2c. 人+道具+姿势证据链场景（2026-09-25 用户口述决策，第三条路径，预研登记）

**场景**：钓鱼/野营/野炊/烟火等动态、无固定位置的场景级目标——单靠物体检测无法表达「人在做什么」，需证据链融合。**登记为预研专题**（research/2026-09-25-人道具证据链场景专题.md），**不占 31 入训类名额**；当前样本≈0，启用触发=场景样本积累到位。

**核心设计**：人检测为锚 →
- **分支 A**（纯机器近零成本全量跑）：区域放大后细道具检测器（鱼竿/鱼线/鱼护/钓箱/折叠椅/遮阳伞/烧烤架/帐篷/天幕/吊床/抄网/打窝勺/营地灯等，逐场景清单见专题文档）+ 姿势分类器 + 证据融合规则；
- **分支 B**（两手准备）：中置信才调 VLM，裁切放大区域（避免全图干扰与分辨率损失）。

**烟火独立线**（优先级最高）：技术成熟（YOLO-fire/smoke 现成）+ 风险价值高 + 无人出现也报。

**业务确认（s4 会话，事件域语义 owner）**：钓鱼/野营/野炊/烟火**不在当前 TU 封闭事件类型表内**，但属于合法扩展消费范围——① 烟火/明火线恰好为 **ET10 突发情况**提供了具体检测能力（该类本「无模板、无封闭类集」，design §0 由判定层兜底的空档由此补上）；② 钓鱼/野营/野炊证据链可经 **scene 202/203 动态 prompt**（开放式目标短语）消费。v1 s4det 范围不变（31 类），本专题样本积累与预研不阻塞主线。

**三路径分派总则（汇总）**：① 检测器主路径——动态可移动、形态确定目标（垃圾/车辆/摊位等 31 类）；② GPS+视频+VLM 哨兵路径——静止固定、形态/边界不确定目标（billboard/sculpture，§2b）；③ 证据链场景路径——动态无固定位置的场景级行为目标（钓鱼/野营/野炊/烟火，本节；烟火独立线可先行）。

## 3. 标注规范 v1 要点（P1 产出完整版 `annotation-guideline.md`）

1. 小目标：见 D1——可辨认即标，无尺寸下限（聚类阶段统计实际尺寸分布后若发现大量 <16px 目标再议）。
2. ROI 灰化：见 D1′；ROI 定义存项目数据根（版本化），灰化参数单一数据源。
3. 堆叠/层叠：见 D2；garbage_pile 边界判据（个体可辨比例）写入规范并配例图。
4. 遮挡=可见框；截断=框到图像边缘为止（不估界外）；两者规则分离。
5. 区域现象类（积水/油污/道路破损/散落垃圾区/施工区）：框整个可见现象区域，「紧框」=现象边界而非实体轮廓。
6. 状态类载体：charging_bike（车+飞线复合形态，聚类验证是否成立）；占道经营→shop_display 载体。
7. 负样本：保留无目标事件图入训练集（教模型「没有」）；毒帧清洗后删框留图（skill ⑩）。
8. 全库一致性：本规范冻结后新老标注同规；修订走版本号+重抽检。

## 6. 评测参照集（j-eval-benchmarks 六要素）

- **必产出**：人工裁决级 GT 集——分层抽样（叶类×域×尺寸段），人审框+类，规模 ~500-1000 张起步；

## 7. 风险与开放项

1. 平台码逆向失败 → fallback 仅用 llm_entries 语义（覆盖率降，记录于 EVAL-BENCHMARKS 缺口）。
2. VLM grounding 框粒度粗 → 人工兜底覆盖；vlm_grounding_calibrate 先标定。
3. 类目表早期震荡 → v1 冻结纪律 + 待观察类目区。
4. 多类改造范围（det_mine/TargetProfile）可能扩大 → shtm 5 类先例为参照，jxl 会话评估后回报。
5. 单模型全类 vs 按域分模型的取舍 → v0 先单模型；若按域指标互拖，再议拆分（记录判据）。
