# s4det 标注-训练循环总方案（纲领文档，2026-09-25）

> 核心目标（用户口述）：**训练高质量、高精度的检测器**。路径 = 机器标注为主的标注-训练循环，多轮迭代逼近「合适」。
> 本文档为 jxl 会话执行纲领；类目语义权威 = taxonomy.md，架构权威 = design.md。

## 1. 核心目标与「合适」的定义

- 核心目标：训练高质量、高精度检测器。
- 质量标准是「**合适**」而非「完美」：标注以机器为主（jxl 机制 + 大模型），人工只干预少量难例——沿用 sgcc/n001 已验证的飞轮方法论。
- 质量的唯一锚 = 人工 GT 参照集（T4，滚动建设）。**T4 未覆盖的口径，内部指标一律不作质量结论**（WARNING-1，n001 虚高 0.895 教训）。

## 4. 标注-训练循环设计（M1 已实跑，M2/M3 复用同一骨架）

```
        ┌──────────────────────────────────────────────────────┐
        │                                                      │
  ┌─────▼─────┐   ┌──────────┐   ┌──────────┐   ┌─────────┐  ┌─┴────────┐
  │ 数据到达   │ → │ 机器标注  │ → │ 难例筛选  │ → │ 人工兜底 │  │ 合并训练  │
  │ mine/弱标签│   │ 伪标+共识 │   │ 争议/低置信│   │ (少量)   │  │ 训练+评估 │
  └───────────┘   └──────────┘   └────┬─────┘   └─────────┘  └─────────┘
   新数据到达必触发   det_mine 级联     doubao/vlm 仲裁       review_       consensus_
   (data-flywheel)   + vlm_pool        (vlm_pool 局域网      workbench     dataset→jxl_
                     四模型池           优先,商用抽检)        少量终裁       split→yolo_train
                                        └→ 未决样本入隔离台账              → T4 同集评估
                                                                              │
                                              新模型上 ←──────────────────────┘
                                              (新模型巡检全量→误报/漏报→回流 mine)
```

### 每环工具映射（全部为既有件，无新依赖）

| 环节 | 工具 | 验证状态 |
|---|---|---|
| 数据触发 | data-flywheel 触发机制 + preannot（b_preannot） | ✅ 批 1 |
| 机器标注 | det_mine（validators 级联）+ vlm_pool（四模型仲裁） | ✅ 批 1 实跑 |
| 难例筛选 | 争议分/level 分层（L0/L1/review）+ conf 分档 | ✅ 批 1 |
| 人工兜底 | review_pack → review_workbench（低频、少量、hardcase） | 机制就绪 |
| 双闸审计 | vlabel-label-audit gate + cluster | ✅ 批 1 |
| 合并 | consensus_dataset（多类多源）→ dedup_gt_boxes → jxl_split | ✅ 批 1 |
| 训练 | yolo_train（官方 COCO 底座；规模适配双向检查每轮记录） | ✅ D0 |
| 评估 | T4 参照集同集对比（叶类 mAP + 尺寸段分项） | ⏳ T4-b1 待人审 |
| 回流 | 新模型 mine 全量 → 误报/漏报/低置信 → 下一轮输入 | 机制= data-flywheel |

### 迭代节奏（数据到达驱动 + 轮次里程碑）

- 一轮 = 「数据扩充/类目调整 → 机器标注 → 兜底 → 重训 → T4 同集评估 → 轮报」；
- 轮触发：新数据到达、类目变更、上一轮评估不达标——不按日历硬排；
- 每轮必产出：轮报（数据量/类目变化/指标/T4 对比/遗留）入 `tasks/` 执行记录，指标入 EVAL-BENCHMARKS；
- 成本/进度每批回写（C-seedset 惯例）。

## 4b. 模型能力差异化权重（强模型多承担，权重经测试验证）

原则：**权重不是拍的，是标定出来的**——每个模型在我们域、我们的 GT 上实测 F1，权重随实测走。

1. **投票权重**：vlm_pool/det_mine 的模型权重 = T7 域内标定 F1 归一化。批 1 实测：qwen-flash 0.875 / qwen35b-local 0.76（强票）/ glm-flash 0.33（降为仲裁票）——与「强票/仲裁票」二元制并存，强票内部再按 F1 加权；
2. **每轮重标定**：L0 GT 每轮更新（模型/数据分布都变了），标定报告随轮入 EVAL-BENCHMARKS——权重漂移即可见（SAM3 verifier 随数据引擎同步迭代同构）；
3. **数据比重**：入训练集时按框的**产生来源加权**——高标定置信模型组合产出的框优先入选/低置信来源框设更高淘汰阈；每框 provenance（来源模型组合/仲裁状态）已在 clusters/layers 中记录，训练侧可追溯；
4. **verifier 蒸馏路线**（SAM3 工业先例）：仲裁 accept/reject 历史积累后蒸馏小分类器，替代部分 VLM 商用调用（吞吐约 2×，成本降）——批 2 数据量起来后启动；
5. **MV+EV 双验收补全**：gate 查「标错的」（MV）已有；「漏标的」（EV）用 vlm_pool 的 vlm_only 挡（共识位置外同见目标）+ 位置卫兵负簇——批 2 纳入固定审计项。

## 4c. 滚雪球数据策略（控代价、逐步滚大；借鉴 SAM 数据引擎）

**不能全量加**：全库 13.8 万帧 × 全类一次上——标注/训练/治理成本爆炸且毒标注风险集中。按 SAM 三阶段递进 + 阶段门控：

1. **轮次门控（阶段门控，防坍缩）**——轮 N+1 扩张需同时满足：
   - T4 参照集评估达标（按类设 mAP 门槛）；
   - 人工兜底占比较上轮**下降**（模型变强的直接表征；人工量只增=模型没长进，禁扩张）；
   - 双闸审计干净（gate 拦截率与毒簇无恶化）。
2. **单轴扩张**：每轮只开一个轴——①类目扩张（批 2 +12 类）②数据量扩张（已训类 mine 新月份/新机位）③难例深化（低置信/边界样本专攻）；
3. **每轮数据预算**：每类每轮新增 ≤~1,000 标注帧（批 1 实测：800 帧机器标注半天 + 一次人工窗口），预算内按第 4b 条权重选样本；
4. **难例集中在人工**（SAM Stage2 精髓）：机器预填高置信样本，人工只裁机器不确定的——人力永远打在多样性前沿；
5. **数据膨胀对冲**：单类数据超预算后用 sample_prune（簇内削减，20% 甜点档实测近零损）+ coreset 代表选择（yolo_coreset）控制训练集规模——滚雪球滚的是**覆盖度**，不是体积；
6. **主动挖失败点**（SAM3）：每轮评估后，模型失败样本（漏检/误检簇）= 下轮数据采集重点——与 data-flywheel 的 mine 回流同一机制；
7. **评测集永不模型辅助**（SAM2 铁律）：T4 人审 GT 纯人工，已物理隔离。

## 6. 开放问题（已提交用户/s4，答案回填本节）

- Q1 人工窗口节奏（决定循环人工依赖度）：119 帧兜底 + T4-b1 何时开窗，此后固定节奏？——**待用户**。
- Q2 M3 区域现象：训练独立模型 vs VLM 后置不训？——**s4 会话裁定（2026-09-25）：v1 VLM 后置不训**。依据：① 现象类事件本就被平台预筛（积水 3.3k 等为事件级到达，非全图扫描），VLM 后置的量可控；② 现象 bbox 紧框语义弱（水痕边界/反射混淆），M3 训练需从零打区域框，成本前置而收益后置（YAGNI）；③ 数据继续经 road 批 VLM 打框积累，若 VLM 成本超阈值或出现离线部署需求，再启 M3（模型可复用 M1 骨架）。用户可否决。
- Q3 烟火业务确认：是否属 s4 消费范围——**s4 会话已确认（2026-09-25，design §2c）**：属合法扩展消费范围；烟火线补 ET10 突发情况能力空档（原「无模板无能力，判定层兜底」），钓鱼/野营经 scene 202/203 动态 prompt 消费。M0 可独立启动。
- Q4 T4 滚动节奏：每轮 GT 扩多少——**s4 会话确认（2026-09-25）：每轮 +100~200 帧随类目扩展**，与 T4 规范 §5 滚动计划（600 帧目标）一致；配额按新入训类均摊、负样本保持 10-15%。
