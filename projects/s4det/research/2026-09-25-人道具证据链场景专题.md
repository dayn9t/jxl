# 专题定义：人-道具-姿势证据链场景（动态无固定位置复杂事件）

> 来源：用户口述（2026-09-25，jxl 会话整理转写）。**当前样本≈0，不进 taxonomy 入训类**——预研专题，样本到达或业务确认后启用。
> 定位：s4det 三条检测路径之三（检测器主路径 / GPS 哨兵路径 / **本专题：证据链级联路径**）。
> 待 s4 会话落档：taxonomy 候选类登记 + design 路径节。

## 1. 定义与特性

**场景事件 = 人 + 道具 + 姿势 + 环境的组合证据，单独任何一项都不构成事件。**

与另两条路径的本质区别：

| 路径 | 目标位置 | 目标形态 | 判定单位 |
|---|---|---|---|
| 检测器主路径 | 任意（动态） | 确定、边界清晰 | 单目标 bbox |
| GPS 哨兵路径 | 固定（GPS 可缩范围） | 不确定 | 状态对比（图+描述） |
| **证据链级联（本专题）** | **任意（动态，无法 GPS 缩范围）** | **主体模糊、道具细微** | **证据组合的场景判定** |

关键难点：**证据粒度倒挂**——事件级别（钓鱼/野炊）远大于可见粒度（鱼线细如发丝、中远距离鱼竿只是一条斜线、姿势只有轮廓）→ 单级检测器/单级 VLM 均不可靠，必须级联。

## 2. 场景归类（用户点名 + 同构扩展）

| 场景 | 风险级 | 核心证据 |
|---|---|---|
| **钓鱼** | 中（水域安全） | 人+水边+竿/伞/椅组合 |
| **野营** | 低 | 帐篷/天幕/吊床+人 |
| **野炊/烧烤** | 中高 | 人+烧烤架+明火/烟 |
| **烟火/明火/烟** | **高（独立风险事件，可脱离场景单列）** | 烟柱/明火/火星 |
| 放风筝（同构扩展） | 低 | 人+线+高空风筝 |
| 占道晾晒（同构扩展） | 低 | 杆/绳+晾晒物+沿路布局 |

烟火特殊性：本身是成熟技术线（消防 AI，公开数据集/模型充足），且**不需要人作为锚点**（无人野火也要报）——建议独立检测线，兼作野炊场景的证据源。

## 3. 证据链分解（四层）

1. **人（一级锚点）**：先有人，才谈场景。检测器成熟，全帧可跑。
2. **姿势（二级，弱证据）**：坐/蹲/立 + 面水/持竿轮廓——细节看不清时往往仍有特定姿势。pose 估计或姿势分类器。
3. **道具（二级，强证据）**：中近距离可检；见 §4 清单。
4. **环境上下文（辅助）**：水体边缘、绿地、空地——缩小场景先验。

## 4. 道具清单（按场景；用户口述+补充）

- **钓鱼**：鱼竿、鱼线（细线，中远距离不可见→只作近距离证据）、鱼漂、鱼护/鱼篓、水桶、钓箱、遮阳伞、折叠椅/马扎、抄网、打窝勺
- **野营**：帐篷、天幕、吊床、防潮垫/野餐垫、睡袋、营地灯
- **野炊**：烧烤架/烧烤炉、炭火盆、锅具/炉具、食材箱/保温箱
- **烟火**：烟柱、明火、火星
- **跨场景共用**：遮阳伞（钓/野营/摊位共用，不单独定场景）、背包、载具（三轮/自行车）

标注注意：道具多为「细长」（竿/线）或「低矮」（垫/椅）——检测框规范需在 annotation-guideline 增补细长目标条目。

## 5. 级联架构（用户两分支设计 + 烟火独立线）

```
全帧检测（廉价层，全量跑）
  ├─ 人检测（成熟模型）
  ├─ 烟/明火检测（独立线，命中即高优先事件 + VLM 复核）
  └─ 大体量道具检测（帐篷/遮阳伞——够大，全帧可检）
        │
        ▼ 以人框/道具框为锚，裁切邻域放大（避干扰+提分辨率）
        │
  ├─ 分支 A【纯机器，低成本，可全量】
  │    ├─ 区域放大后再检测细道具（鱼竿/折叠椅/烧烤架）——检测器+检测器级联
  │    ├─ 姿势分类器（坐/蹲面水轮廓）
  │    └─ 证据融合规则表（人+水边+竿 ∨ 人+伞+椅+水边 → 钓鱼 等）
  │         → 高置信：直出事件 / 低置信：丢弃（入隔离台账）
  │         → 中置信：转分支 B
  │
  └─ 分支 B【VLM，按需，控成本】
       裁切放大区域 → VLM 结构化问询（场景类型判定 + 证据清单输出）
       prompt 给出候选场景与道具清单，要求逐项确认
       → 确认/否定/不确定（不确定→人工兜底）
```

**两手准备的成本逻辑（用户裁决）**：分支 A 与 B 功能重叠但都要做——A 全量跑近乎零边际成本，拦截绝大多数帧；B 只接 A 的中置信输出，调用量可控。任何一级都不单独依赖：A 漏的 B 补，B 的结果可回灌 A 的证据融合规则（提示词反哺同构）。
