# s4det 目标分类学与数据源盘点（2026-09-25）

> s4det 项目首份资产：三路并行调研（s4 仓目标枚举 / jxl+vlabel 能力 / 事件数据资产）+ 外部标注实践检索 + 用户需求存档的汇总。
> 用途：类目表 v1 与标注规范的证据基础；s4 与 jxl 两侧会话共同引用。
> 注：文中文件路径均相对各自仓库根（s4 = /home/jiang/cc/next/s4；jxl = /home/jiang/cc/py/jxl）。

## 0. 用户需求与决策存档（2026-09-25 会话要点）

1. **近期目标**：训练一个检测器，把所有事件相关目标**全部**检测出来（"是全部"）。
2. **任务分解**（用户指定）：① 经程序+全部提示词获取所有目标信息；② 盘点 jxl 标注数据飞轮能力并在 jxl 内建项目子目录承载工具/代码/临时物；③ 盘点事件图片资产；④ 调研第三方堆叠目标标注最佳实践；⑤ 详细整理成计划，疑问用 brainstorming 讨论。
3. **小/远目标**：不太关注，阈值未定。理由（用户原例子）：机动车违章停车若目标太小太远，无法判断其停放地面是否合规区域，判定层无法用。是否从**检测模型训练集**剔除——用户不确定，担心影响检测准确度。
4. **堆状目标**：一堆垃圾层叠遮挡如何标是标注界难题。用户旧经验：密集度高的整体作为一个对象标「垃圾堆」；其中可辨个体（较鲜明的垃圾袋）可逐个标。
5. **层叠非机动车**（共享单车/并排停放）：从不好视角看层层叠叠，有的仅露一条。两难：不标（露出部分大时影响训练）vs 标（太不完整）。要求认真搜索最佳解。
6. **平台目标信息**：较新事件图片已有商用大模型目标信息（平台预检框），可利用但可能有较多遗漏。
7. **类目粒度**（用户提出，方向已倾向细分）：大类笼统在 prompt 里可接受，作检测器类别有问题——一个大类实际含形态差异大的多个细类；细分对检测器帮助更大，代价是类数增加。细分依据：抓取图片后做聚类，把大类聚成若干小类。利弊权衡已交 Claude（见 §6）。
8. **跨仓操作模式**（会话中裁决）：jxl 仓的活（工具开发/飞轮运行/训练）由 jxl 会话执行，s4 会话以文档交接；分界细则见本目录 README「操作归属」。
9. （时效性，已过期）会话初期临时限制并发 agent ≤3，一小时后解除。
10. **ROI 灰化**（Q1 拍板时用户补充）：既往标注惯例——对与关注目标不相干/难以取舍的目标区域，用多边形圈定 ROI、ROI 外以特定灰色填充，把两难目标排除出训练视野；py（vlabel `a2d.py` ROI 对象族）与 n001 stage2 灰化先例可复用（机制与坑见 skill j-consensus-labeling ②）；ROI 确定需人工或大模型参与。
11. **跨项目信息完整与互链**（2026-09-25 用户要求）：跨 s4/jxl 两项目工作，任何一侧不得只见部分信息；两侧文档间多建链接、相互参照印证。入口已建：s4 侧 CLAUDE.md + docs/TODO.md ↔ jxl 侧 docs/INDEX.md + projects/s4det/README。

## 1. 结论速览

- **目标全集**：mobile 19 类 EventType（其中 4/5/8/9/10 无模板不参与）+ road 8 类部件（7 未启用）+ scene 202 静态 8 组 + 203 全动态目标词 + judge 两链（parking 非机动车族 / barrier 隔离栏）。检测器承接的是其中的**实体/区域**，状态关系类只标载体（§6-7）。
- **数据**：事件图片 ~21.3 万张（4 个月）。mobile 平台预检框覆盖 98.3%（归一化 4 点矩形，Confidence<50 占 35%）；road 3.7%、scene 0%。mobile llm_entries 78% 提供双模型独立分类+grounding 框。
- **弱标签最优组合**：平台框（位置先验）+ llm_entries doubao/qwen 一致类别（语义）；仅作预标注/共标注起点，不直接当真值。
- **jxl 侧**：数据格式层（vlabel）与训练层已多类就绪；瓶颈在共识产出层（det_mine 等单类 TargetProfile 假设）。shtm 已有 5 类先例。
- **外部实践**：遮挡→可见框+可见比阈值（CrowdHuman/CityPersons）；堆状→个体+整体混合或 aggregate（业界认可用户旧做法）；小目标→不可不标留假阴性，标全+推理侧过滤是正解；YOLO 无原生 ignore region。
- **粒度裁决**：两级类目表——叶类（视觉内聚，检测器标签）→ 事件粗类 many-to-one 映射；细分由数据聚类驱动，硬条件=视觉可辨∧样本量≥阈值。

### 2.3 scene 域

- **202（视频，56 条）**：静态 keyword 表 + 槽模板（scene_classifier.rs PromptMap，`event.prompt.contains(keyword)` 命中）。8 组：邮筒（破损倾斜小广告）/违规停车（人行道上违停机动车，轿车货车面包车；非机动车不算）/垃圾（TARGET=垃圾箱，破损倾斜脏乱）/反光镜/经营状态（店铺关门停业或脏乱）/消防栓/配电站/雕塑。
- **203（事件闭环，11,572 条，99.5%）**：全动态——`{PROMPT_DESC}` 槽注入每事件 prompt，目标词不可穷举（词频见 §3.4）。

### 2.4 judge 判定链（二级判定）

- **parking**（mobile EmergencyType=2）：三段 prompt（`deploy/event-judge/cfg/s4-judge-plugin-sample/ref/2_tmp.md`，与 mobile/ref/2_tmp.md 同源）。Pass1 Detect 关注：非机动车（自行车、共享单车、电动车、摩托车）+ 机动车（汽车、卡车、公交车）+ ride_state + rider_visible；Pass2 Locate 区域识别（路缘石高差/沥青vs铺装砖/白线/红色铺装）；Pass3 Compliance（rules.md：阻碍通行/占红色非机动车道=违规；人行道=正常）。输入 proposals=平台 objects 全量（含 "11," 非机动车，后缀 `[r,c],[r,c]` 网格子区位）。
- **barrier**（road type=6）：prompt 代码常量（py/s4-judge/.../barrier.py），语义对齐 road/6.md；输出整栏归一化 bbox；不消费 proposals（平台 Objects 现为空）。

## 5. 外部标注实践（检索结论，2026-09-25）

1. **遮挡两路线**：可见部标注（visible-part）vs 整域 amodal；遮挡（被物体挡）与截断（被图像边缘切）分开定规则；"tight 到哪里"必须写进规范（标注噪声主来源）。（basic.ai / cntxt.tech）
2. **层叠个体标准解**：CrowdHuman 三框（头/可见框/全身框）+ ~9 万 ignore region（匹配检测不计 TP/FP）；CityPersons 提供可见框+全身框双标注、重度遮挡（可见比<35%）与远距入 ignore；实证「对齐框+ignore region 训练优于其他形态」。
3. **堆状目标**：TACO 逐件杆 vs 违规倾倒识别的整域杆（dump site 整体分割）；共识=件间遮挡超阈值后逐件不可靠 → amodal / 堆整体+个体混合 / 密度计数。**用户「垃圾堆整体」旧经验落在受认可的 aggregate 杆上**。
4. **小目标**：不标注的小目标在训练中=假阴性监督，主动毒化模型（用户担心「剔除影响准确度」的机制根源在"留图不标"而非"剔除"）；正解=照标 / ignore region / 点监督；业务上"不关注"应落在推理后过滤。**ultralytics YOLO 无原生 ignore region**——训练侧只能「标全」或「图不入集」，评测侧可自定义。

## 6. 粗细粒度权衡（两级类目表方案）

**结论：两级类目表——叶类（检测器标签，视觉内聚、EN 短名）→ 事件粗类（EventType/部件判定用途）many-to-one 映射表。**

- 支持细分：类内形态方差是分类精度直接杀手（「丢弃垃圾」横跨编织袋/床垫/家具/木材/动物尸体，无共享视觉特征）；细→粗查表可逆、粗→细不可逆；细分令 VLM prompt/形态词典/难例归集全链受益。
- 代价与对冲：长尾小类（硬条件：视觉可辨 ∧ 样本 ≥50-100 张，不满足并回母类入隔离台账）；纯语义不可视区分不拆（红线）；早期震荡（v1 冻结=粗类+已证实大方差细分，其余待观察）。
- 细分产出流程：按粗类抓图 → DINOv3 embedding（embed_dino）→ Faiss 聚类（dedup_sem 机制 cos~0.85）→ 簇代表网格（review_pack）→ 人工命名/合并 → 形态词典 v1 → 冻结两级类目表。
- **性质分层**（类目表必答项）：实体类（常规 bbox 细分候选）/ 区域现象类（积水/油污/破损/散落垃圾区——bbox 可行但"紧框"定义单独写）/ 状态关系类（违规充电/占道经营——检测器只标载体，违规性留判定层）。
