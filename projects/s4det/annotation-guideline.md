> 例图：待任务书 A 簇代表网格产出后回填（节内标 ⬜例图 处）。

## 1. 总则

1. **两级类目**：标注用**叶类**（taxonomy.md 冻结表，EN 短名）；上报/判定用粗类映射查表。标注员不得自创类；候选新类 → hardcase 轨道核实 → 词典/类目表修订流程。
2. **单一数据源**：类目定义=taxonomy.md；形态要点=形态词典；本规范只管「怎么画框、怎么取舍」，不重复类定义。
3. **同源纪律**：人工标注所见图必须与训练图**同源灰化**（n001 返工教训）。
4. **宁缺毋毒**：任何不确定目标不硬标——分歧/低质入隔离台账（j-quarantine-ledger），禁止无声丢弃。

## 2. 全标原则（D1）

- **凡人类可辨认的目标一律标注，无尺寸下限**。可辨认 = 能说出「这是什么叶类」且边界可指（哪怕只露 25%）。
- 「不关注小/远目标」落在**推理后尺寸过滤**（阈值待与判定层联调标定），训练集不做尺寸取舍。
- 红线：**禁止「留在图里但不标」**——假阴性监督毒化模型（比错标危害更大）。
- 确实无法辨认的微小目标（说不出类、看不见边界）：按 §9 ROI 灰化处理或该图入隔离台账，不留悬案。

## 3. 框的画法

| 规则 | 内容 |
|---|---|
| 可见框原则 | 框**可见部分**（visible-part，CrowdHuman 路线）；不做 amodal 估界（v1 不做，D2） |
| 遮挡 vs 截断 | **遮挡**（被物体挡）：框可见部，被挡边界顺主体轮廓合理收口；**截断**（被图像边缘切）：框到图像边缘为止，不外估 |
| 紧框 | 实体类：贴目标可见外缘（含轮胎/车把/外包装等本体，不含阴影与投影） |
| 重叠 | 相邻同类目标各自独立成框，不合并（群/堆例外见 §6/§7） |

## 4. 区域现象类画法（积水/油污/道路破损/散落垃圾区/施工区）

- 框**整个可见现象区域**：紧框 = 现象边界（水痕/油渍外缘、破损裂缝影响区、散落物散布范围、围挡外缘），非某件实体的轮廓。
- 现象边界模糊时：框「有把握是现象」的内核区，模糊过渡带不硬扩；整体不确定 → 隔离台账。
- 现象内可辨实体（积水里的纸箱等）**同时**按实体类另标（一图多框，框框独立）。
- 散落垃圾：≥1㎡ 或数量多（≥4 件）成区 → `scattered_garbage_zone` 区框 + 区内可辨个体逐件标；1~3 件细小垃圾不构成区，按个体标。

## 5. 状态类载体画法

- **违规充电** → 标载体 `charging_bike`（助动车+飞线/充电器复合形态；聚类验证不成立则拆为 bike + 飞线不标）。飞线细若不可辨：只标车，不虚构线框。
- **占道经营/店外展示** → 标载体 `shop_display`（货架/商品陈列区外缘）。
- **违规性本身永不入标注**（判定层职责）；状态语义存 crop 元数据备判定层取用。

## 6. 堆状目标（D2 混合式）

1. **可辨个体**（轮廓鲜明、能定叶类：单个垃圾袋/泡沫箱/家具）→ 逐件标叶类，框可见部（§3）。
2. **密集堆体**（个体互相叠压、逐件不可辨）→ 整体一框 `garbage_pile`（aggregate 类，业界认可做法）：
   - 边界 = 堆体外缘（含明显凸出的个体，不含散落地面的孤立件——孤立件按 1 另标）；
   - **判定口诀：能数得清的数（逐件标），数不清的框堆（pile）**；同一堆内允许「数得清的 N 件 + pile 剩余体」并存（pile 框避开已单独标注的鲜明个体）。
3. pile 内密度差异大时：可按视觉密度拆 2-3 个 pile 框，不强求一框。
4. 例图参考（P3 标注时按此取例）：`/mnt/data/s4det/p0-cluster/garbage/grids/review_grid_001.jpg`——c03 混合不可数堆（pile 标准例）、c04 白袋堆（个体可数与堆体边界例）、c01 吨袋（个体大件例）；c14 篷布覆盖车（hardcase 例，观察类）。

## 7. 层叠非机动车（D2）

- **可见比例 ≥25%**（可见面积/完整估面积）：标 `可见框`——只框露出部分，不顺主体补全（CrowdHuman 可见框制）。
- **<25%**：不标。该区域密集层叠成片时 → §9 ROI 灰化候选（用户拍板的两难目标出路）。
- 露出「仅一条车身」但可辨叶类的，按 ≥25% 规则执行（可见部大于阈值即标，宁全标）。
- 成排并排（相互不遮挡或轻遮挡）：每辆一框，不合并群框。
- 例图参考：`/mnt/data/s4det/p0-cluster/vehicle/grids/review_grid_001.jpg`——c01 并排停放（每辆一框例）；注意 c02/c05/c06/c07/c10 右列码 12 均为**地面区域框非目标框**（CODEBOOK 已定性），不得当车辆标注。

## 8. 平台预标注的信任级与用法（弱标签入口）

| 层 | 来源 | 用法 |
|---|---|---|
| 预标注 | 平台框（位置）+ llm_entries doubao∧qwen 一致类别（语义） | 自动生成 proposal；码 11 框高优先，码 12 框降权（CODEBOOK）；Conf<50 只入候选档 |
| VLM 共识 | vlm_pool 四模型池（标定后） | 仲裁预标注分歧 + road 第二批打框；调用失败=弃权票 |
| 人工 | review_workbench / VLabel | 分歧、pending、弱类、边界形态（§6/§7 全部 hardcase）终审 |

- 预标注进训练集前必须过**质检双闸**：label_audit gate（k≥2 ∧ strong≥1）+ cluster 位置卫兵（n001 毒标注教训，skill ⑩）。
- 平台框当 proposal 用，**不得直接当真值入库**（Conf<50 占 35%，且类别码语义残缺）。

## 9. ROI 灰化（D1′）

- **何时用**：① 两难目标成片（层叠车 <25% 密集区）；② 与检测目标无关的干扰区（商铺内部、绿化深处等既往惯例区）。
- **怎么做**：多边形圈 ROI → ROI 外以训练灰化色填充后入集；ROI 定义（多边形顶点）版本化存数据根，灰化参数单一数据源（一处定义，标注图/训练图/VLM 判定图同源）。
- **机制复用**：vlabel `a2d.py` ROI 对象族 + n001 stage2 灰化先例（涂灰区几何计算的坑见 skill ②）。
- **粒度**：按**摄像头机位**级定义（同一机位 ROI 复用），不做每图手画。

## 10. 负样本

- 无目标事件图**保留入训练集**（教「没有」，防全图误检）。
- 毒帧清洗后：**删框留图**（负样本化），图片永不删（n001 手术纪律）。
- 负样本与正样本比例不人为配平，按自然分布（当前无目标事件占比高属正常）。

## 11. 易混边界速查（细则归词典，此处只列判据）

| 易混对 | 判据 |
|---|---|
| garbage_bag vs garbage_pile | 单件可辨 → bag；叠压不可数 → pile |
| 丢弃垃圾 vs 占道堆物（粗类） | 凌乱=垃圾、整齐=堆物（misc.md 原文）；叶类层面只管形态，粗类归属查映射表 |
| scattered_garbage_zone vs garbage_pile | 散布（面积 spread，≥1㎡）vs 堆叠（体积集中） |
| stall_cart vs shop_display | 流动/无固定门面 vs 有门面外溢 |
| charging_bike vs bike | 有无可见飞线/充电器连接；拿不准 → bike（hardcase 归集） |
| water_puddle vs oil_stain | 颜色/反光（油污虹彩、深色）；拿不准 → 现象类并标候选入隔离 |
