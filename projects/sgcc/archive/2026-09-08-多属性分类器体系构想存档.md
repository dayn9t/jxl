## 1. 核心构想

在检测框 crop 级建立**多属性标注体系**（multi-label，非互斥单类）：

- 属性例：`is_person / upper_body_visible / head_visible / face_visible / is_partial(肢体/碎片)`…
- 属性值正交，每个布尔属性对应一个二值分类头；类别体系**未定型**（用户明确「还不完全确定有哪些分类」），架构必须可扩展
- 首个业务需求（当前唯一）：**「上半身大体可见」**（不一定含头）——收费窗口场景
- 判定均为「框内这个人」的 crop 级属性

## 3. 架构：独立分类器族（2026-09-08 用户裁决，替代早期"多头 BCE"方案）

**用户裁决：不同分类器不坐在一起**（担心 multi-task 负迁移互相影响），训练多个独立分类器
（工具链成熟=全部 ultralytics 标准流程，零自研训练代码；失败隔离；单属性可独立重训/替换，
适配循环化逐属性迭代）。早期"同 backbone 多 sigmoid 头"方案**作废**。

结构（「互斥粗类」与「布尔属性」区分对待）：

- **分类器 1（粗类，原生多类 softmax，非多任务）**：
  `non_person / person_upper / person_full / person_partial`——四类天然互斥，单头 softmax
  最成熟形态无互扰；一个模型双用途：审计第一道初筛（non_person）+ 上半身业务（upper∪full）
- **分类器 2..N（布尔属性族，每属性独立二分类器）**：
  `head_visible / face_visible / ...` 各一个 yolo26l-cls binary——互相独立，「不坐在一起」
- **标注一次性取齐**（付费约束）：VLM 第一次调用起就按全属性 schema 回收
  （粗类 + 全部布尔属性 + uncertain），属性库一次建全（差集 16,352 框 + 训练集 18,999 框
  一批跑完；局域网 qwen3.5-35b 免费，商用 doubao 仅质量抽检）——之后任何新分类器
  直接从属性库取数训练，**不再二次付费调用**

## 4. 数据造集设计

```
多模型标注框并集 → dino embed 聚类去重（复用 dedup_sem/yolo_coreset 基建）
  → 簇代表多样性采样（正负样本天然均衡）
  → VLM 一次调用产全属性（属性词典口径，见 §5）
  → 属性库（stem + 属性向量 + provenance）
```

- 一次调用回收 N 属性：图像 token 是大头，多属性输出近零边际成本
- 类不平衡对策：负例从差集无人帧/物体 crop 定向补（upper_body 在窗口场景几乎恒 True）
- 属性分组 ≤6 个/次 + 结构化校验重试（防长 schema 输出劣化）

## 5. 属性词典 V2（2026-09-08 用户裁决：精简 9→6 + 增补年龄）

**标注 5 判定字段（k≤10 安全区）；训练 V1 仅 2 个分类器，head/face/age 缓建（数据先入库）。**
精简依据：is_partial=粗类镜像冗余砍除、is_person 并入粗类判据；head/face 无当前业务缓训。
年龄=PAR 标准属性（PA-100K Age/UPAR 组内互斥先例），用户 2026-09-08 指定四档。

| 标注字段 | 类型 | 操作化定义（含 PAR 调研修正） |
|---|---|---|
| 粗类（non_person/person_upper/person_full/person_partial） | 互斥 4 类 | amodal 分母（可见比例相对完整部位估计，非相对检测框）；柜台截断=一等分布；玩偶/海报/雕像/镜面→non_person（CityPersons fake-human 判例） |
| upper_body_visible | 布尔 | 躯干（肩线至腰）轮廓可见≥50%；手臂降辅助证据（RAP：监控下手臂不可靠标注） |
| head_visible | 布尔 | 头顶至下颌头形轮廓≥50%（含头发/后脑）；戴帽=1；后脑勺=1 |
| face_visible | 布尔 | 面部区域（额-颌、耳前）≥50%，正/侧脸均可；口罩/墨镜=1（判据是区域非五官）；业界无先例，重点抽检 |
| age | **全空间 6 态** | child:体型显著小于成人+面部稚嫩(<12) / teen:体型近成人+面部年轻(12-18) / adult:默认档(18-60) / senior:白发为主∨明显皱纹∨老年体态任二(>60) / **non_person:框内非人** / **uncertain:是人但证据不足**（仅露肢体/逆光/面部不清）。每 crop 必有值。判例：白发染黑中年人→adult(以皱纹/体态为准)；背大书包小个子→child(体型为准)。蕴含校验(R6):age=non_person ⇔ 粗类=non_person——免费交叉质检信号 |
| uncertain | 第三态 | borderline(约 40-60% 可见)或证据矛盾→uncertain；**保留入库不入训练集**，触发 doubao 二审；uncertain 率=词典健康度指标 |

通用约定：image-level（不跨帧传播）；判例式边界入 prompt（UPAR 风格）；属性库切分以 dino 簇为原子防 identity 泄漏。
**用户终审新增口径（2026-09-08）**：人的微小局部（如仅几根头发）**不算可标注的人**——person_partial 下限判例；后续可对存量框补尺寸/可见度分布扫描。
场景预警：窗口场景 teen/child 可能稀缺（年龄分布偏斜），标注后统计实测定补样。
**实锤（2026-09-09 全量 21,744）**：teen 23 + child 4（0.12%）——age 分类器该两档暂不可训。
**补样方案（用户裁决 2026-09-09）**：从公开标注集取——COCO（person 框丰富）等做图像源，
配对带年龄标签的监控属性基准（PA-100K/UPAR 的 Age 组，属性词典 §5 已引）交叉；
流程复用已定型链路：外部图 → VLM 批量判 age 伪标（spark 免费/doubao 提效）→ 只补
child/teen 档入属性库；注意域差（COCO 街景 vs 窗口柜台）只补 age 维度、不混检测训练集。

**训练侧**：V1 = 四粗类 + upper_body_visible 两个分类器（yolo26l-cls / m 档布尔起步）；
head/face/age 三分类器缓建（数据入库备用，业务触发即训）。

## 6. 风险与对策（利弊分析结论，2026-09-08 会话）

| 风险 | 对策 |
|---|---|
| 属性口径模糊（"大体可见"类措辞漂移） | 属性词典操作化定义；VLM/分类器/人工三方同口径 |
| 一次问太多属性→VLM 敷衍 | 分组 ≤6/次 + 校验重试 |
| 类不平衡 | 负例定向补样 |
| 循环口径固化（伪标注锁死模糊口径） | 每属性冻结金标集 + 分歧率监控 |
| 标注矛盾（face=True 而 head=False） | 一致性校验规则（face→head、upper+head 关系） |

## 7. 与循环飞轮的接线（对照 research/2026-09-08-数据飞轮调研.md）

- 分类器=审计管线第一道全量初筛（毫秒/框），VLM 退到不确定尾部——SAM 3 AI verifier 同构
- provenance 三档（human / vlm-verified / auto）+ 双写不删 + 金标冻结永不入训练
- 触发重训：修正量阈值或分歧率上升；champion-challenger 门控

## 8. 启动条件与 500-crop 试跑结果（2026-09-08 深夜完成）

**试跑链路已验证可用**（`gencheck/attr_trial/`，qwen3.5-35b @spark/182，500 crop 分层抽样自带金标锚点）：

| 指标 | 结果 | 判读 |
|---|---|---|
| 解析成功率 | **500/500 (100%)** | ✅ 链路定型 |
| 毒框 50 → non_person | **50/50 (100%)** | ✅ 金标锚点完美 |
| 微小框 56 → non_person/partial | **56/56 (100%)** | ✅ 金标锚点完美 |
| 干净框 394 误判 non_person | 21 (5.3%) | 人工复核拆解：**2 个真毒框漏网**（VLM 反向捞出来）+ 5 微小残片（口径合法）+ **13 明显局部被判 non_person（判例过严，待修）** |
| uncertain 率 | 19.2%（age=uncertain 85 居多） | 偏高但合理（监控远景面部不清）；窗口场景 age 判据天然受限 |

**关键工程结论**：
1. **qwen3.5 必须 `chat_template_kwargs: {enable_thinking: False}` + `response_format: json_object`**——
   默认 thinking 输出 4000+ token 把 JSON 挤出 max_tokens（首跑 71% 解析失败的根因）。
   已入 `docs/infra/spark-vlm.md`；SHTM 批量补标同坑直接命中
2. **判例修正项（待入 prompt V3）**：大面积局部（整条腿/完整头部/躯干）应判
   `person_partial` 而非 `non_person`——non_person 仅限微小残片（单鞋/衣角/几根头发）
   与非人物体；首跑 13/394 (3.3%) 属边界执行过严
3. **VLM 审计副产物**：试跑顺手从存量干净框里捞出 2 个漏网毒框——
   与 label_audit 互补的第三道审计信号（语义级）

启动条件状态：① 手术+重训闭环（v3 训练中，2026-09-08 深夜）✅ 近完成；② 阈值定稿 ✅；
