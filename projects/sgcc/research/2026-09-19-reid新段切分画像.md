1. **切分形态无显著漂移**：段时长分布（p50 212→230s）、多 clip 合并率

2. **新段漂移对入库 221 对**（nd-intra 92 / nd-reconnect 107 / nd-interframe
   22，v2.1 权重 cos<0.62 难例门）。
3. **重要发现——新段 reconnect 族 52% 是异人毒对**：几何重连门（同位置重入）
   在岗位固定场景下大量匹配到「换人占用同工位」，且余弦难例门**反向富集**
   异人对（不同人 → 低 cos → 恰被选为"难例"）。全量 221 对过 spark VLM 同人
   门后只留 107 对，114 对剔除留证。**后续任何新段挖掘，reconnect 族必须带
   VLM 门（或等价人审），单靠 split_points 负过滤不够**（benchmark v3 无新段
   切点，本轮流 0 剔除属预期但等于裸奔）。

## 二、reid 新段切分画像（`gencheck/nd_session_profile.py`）

数据：/var/howell session 树全 468 段（新 175 = 09-05/07/08/17，老 293 =
06-22~09-03；两期 completed 均 100%）。

| 指标 | 老段 293 | 新段 175 | 判 |
|---|---|---|---|
| src1:src2 | 146:147 | 80:95 | 基本平衡 |
| 段时长 p10/p50/p90 (s) | 48/212/794 | 58/230/905 | 形态一致 |
| 段时长 mean (s) / <60s 占比 | 369 / 11% | 359 / 10% | 一致 |
| 时点直方图 | 峰 09-11 时，午后衰减 | 同形 | 一致 |
| **每小时段数（日均）** | 3.21 | **4.36（+36%）** | 密度升 |
| 多 clip 合并率 / 段内最大空档 p90 | 52.6% / 6.0s | 53.1% / 9.8s | 一致 |
| 同 track 拆多段（合并组探针） | 47/293 段=16.0%（20 track；track 间 gap<30s 12/27） | 37/175 段=21.1%（16 track；gap<30s 5/21） | 占比相近 |
| 相邻段间隙 p50 / <10s | 188s / 58 | **20s / 57** | 密度升 |

**判定：新域切分质量无显著漂移。** 所有形态指标（时长、合并率、同 track 拆分
率、时点分布）两期一致；差异全部集中在密度轴（每小时段数 +36%、相邻间隙
188s→20s、09-07 单日 66 段创高）——与检测层新域画像（09 月客流上升、顶带
远场框 ×14）同因。对 reid v2.1 终态结论：**无开题信号**；密度上升只影响
replay 负载与 session 吞吐，不影响切换判据本身。附带观察：新段 step5
118/175 skip（「有效对话内容不足」）系 diarization 塌缩，非切分问题
（见 `2026-09-19-分类器新域画像.md` §二）。
