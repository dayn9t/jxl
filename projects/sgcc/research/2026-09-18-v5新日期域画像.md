## 1. 数据与方法

- **数据源（只读）**：`/var/howell/iap/v0.10/ias/sh-sgcc/n001/video/{1,2}/0/<date>/*.json`，与 mkv 同名一一对应（脚本 fail-loud 校验 json 数 = mkv 数）。每帧 `frames[].detections[]`：`bbox=[x1,y1,x2,y2]`（1080p 像素角点）、`confidence`、`upper_body`。采样 2s/帧（`sample_interval_secs=2.0`）。全库 upper_schema 一致（`2026-09-12_person_upper_n_v2@0.5`），upper% 列跨段可比。
- **日期分组**：历史 v5 = 06-22（训练域内，v5 缓存）；历史 pre-v5 = 06-23~07-06（7 段）；过渡 pre-v5 = 07-31、09-03；新 v5 = 09-05/06/07/08/17（09-18 iap 重检，424 段 mkv 双 src）。
- **口径**：每 src × 日期段一行。有效小时 = mkv 数 ×10min（实测每 mkv 帧时间跨度 ≈10:00）；框/h = 检出数 / 小时；分位数 numpy linear 插值；**cy>550%** = 框中心 y>550px 占比（员工座椅区带，ROI 外误检带）；**upper%** = `upper_body=true` 占比；**扁带%** = cy>550 且 h≤100px 占比（09-06 静物误检实测形态 h 77-82px）。
- **统计脚本**：`/mnt/data/jiang/ws/sgcc/person/datasets/sgcc-n001/crop640_persons/gencheck/domain_profile.py`（只读 `/var/howell`，无参数，输出本文全部表格到 stdout）。复现：`python3 domain_profile.py`。

1. **基线偏高（回归均值）**：06-22 src2 的 cy>550%=47.9 是 src2 各日中的最高值（pre-v5 时代 src2 逐日波动 9.6~40.1，跨 30pp）；且 06-22 是 v5 训练素材来源日，检出分布可能含记忆效应。单日基线 + 最高位起点，向均值回归足以解释大半。
2. **远端小目标召回流失（真退化）**：若 9 月 src2 远端座椅带真有人而 v5 漏检，会呈现同样形态。

旁证倾向解释 1：新段 src2 框/h 还**上升** 8%（漏检通常伴随框量下降）；cy>550 逐日 34.6/33.3/11.2/34.8 与 pre-v5 历史日间波动带完全重叠。但不排除解释 2 与 1 叠加，列为**待复核信号**（见 §8 动作 a）。

## 6. 判定

1. **框/h 突降（漏检风险）：未出现**。src1 -2% / src2 +8%，均在日间波动内。
2. **conf 分布下移（置信度退化）：未出现**。正常营业新段全部 p50=0.9 / p90=1.0，与 06-22 一致；唯二 p50=0.6 的日子（09-06、07-05）都是闭馆静物日。
3. **扁框占比升（误检形态蔓延）：未出现**。两 src 扁带占比分别 -11pp / -18pp；静物误检形态为孤立闭馆日事件且历史已存在。
4. **src2 框高/座椅带同向漂移：待复核信号，非退化证据**（§4）。
5. **是否需要为新域补充训练素材：当前证据不支持紧急补训**。更有价值的前置动作是补基线与抽检（§8）。

## 7. 方法论局限（必读）

- **缓存只含检出、无 GT**：所有「漂移」都是输出分布的间接推断，不是精度测量。漏检若发生（尤其低置信区）在缓存上不可见——框/h 持平不能证明召回不降，只能证明「高置信检出量稳定」。
- **conf 被 0.5 阈值截断**：检出仅保留 conf≥0.5（schema `@0.5`），p50/p90 挤在高区，对置信度整体下移的敏感度有限。
- **v5 历史基线只有 06-22 单日**（缓存覆盖所限，§1 前提修正），单日基线的日间波动幅度（cy>550 可跨 30pp）与部分观测漂移同量级；06-22 又是 v5 训练素材日，分布可能含记忆效应。
- **场景变化与模型行为不可分离**：客流构成、光照、季节都会移动这些指标，本报告无法归因。
- 小样本段：09-17 仅 3.0h / 09-08 5.3h，逐日指标散布大。
- pre-v5 行仅画像参考，跨模型比较不构成漂移证据。
