> 训练机 sgcc0（RTX 4090，用户授权本轮用，不等 sgcc3 部署）。

## TL;DR

1. **验收门（jxl 侧可判部分）PASS**：微调后 held-out 328 对余弦距离分布分离——
   same_p95 = 0.3628 < diff_p5 = 0.4566，**gap = −0.0938**（基座未微调 +0.1159 FAIL）。
   ep6 即翻正，ep42 达 best，早停 ep62 兜底。
2. **重大发现——v1 以来的验收判据方向反了**：`osnet_ft.py` 的 `heldout_gap` 在**余弦距离**值上
   沿用了 iapx §7.4 **相似度**口径的判据标签（same_p5 > diff_p95），实际语义变成「最容易的
   同对 > 最分离的异对」= 惩罚 same 对变近。v1「微调后恶化（−0.565 < −0.4995）」的结论建立
   在反向判据上。本轮修复判据（same_p95 < diff_p5）+ 早停方向后，triplet 微调首轮即翻正。
3. **loss 选择是翻正的关键因子**：circle 三轮（lr 3e-4 / 3e-5，正确口径 +0.074 / +0.083）均
   FAIL；batch-hard triplet（显式压最远正对/拉最近负对 = 直接优化尾部）翻正。数据 4.2× 放大
   了它的效果（v1 的 59 ids 未在正确判据下复测，pair list 已被全量重产覆盖）。

## 判据 bug 详解（证据链）

1. `heldout_gap` 计算 `d = 1 − cos`（距离），却判 `same_p5 > diff_p95` 且 gap>0 过门——
   这是 iapx §7.4 相似度口径的标签（其数值 same_p5=0.750 / diff_p95=0.834 为相似度）。
   距离口径下的正确分离判据 = **same_p95 < diff_p5**（最难同对 < 最易混异对）。
2. 实证：triplet 训练让 same 整体变近（same_p5 0.113→0.032），旧口径 gap 反而更负
   （−0.499→−0.746）——旧口径在惩罚改善。
3. 双口径复算（`osnet_v2_dualgate.py`，基座/三 best/triplet last 五点）确认正确口径下
   triplet 两 checkpoint 均已分离、circle 均未。
4. 修复落盘：`heldout_gap` 判据 + `train()` 早停方向（best_gap 取 min，初值 +inf）。

**对 v1 结论的影响**：v1「pair list 量级撑不起度量学习」的论据（−0.565 恶化）失效；
但 v2 circle 三轮正确口径仍 FAIL 提示 v1 的 circle 大概率同样不翻正——「v1 失败」的
方向碰巧成立，主因应修正为 **loss 与判据错配**（而非纯数据量级）。v1 数据在正确判据下
能否翻正未实证（重建成本高、价值低，如实存疑）。

## 与 iapx ASYM 定标基线（−0.084）的口径关系

**数值不可直接比**（任务书预判命中）：iapx ASYM = 窗内 ≤5 帧主 det 均值 L2 gallery vs
单帧、相似度分位；jxl eval = 单帧 vs 单帧、距离分位。测量法与量纲均不同。本轮「翻正」
的可信依据是**同口径内部对比**（基座 +0.1159 → 微调 −0.0938，同集同法同分位定义）。
§7.4 定标门（ASYM 复测微调权重翻正 −0.084）属 iapx 侧待办。
