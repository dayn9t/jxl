## 3. 双峰判定

- **检测：无明显双峰**。单主峰（0.93-0.98）+ 低位平台（0.50-0.80，10.0%）单调抬升，无谷。
  绝对阈值取平台边缘 p10=0.80，而非谷点（谷不存在）
- **属性：双簇结构明显**。≥0.98 尖峰（sort 80.8% / amount 64.3% / side 88.6%）vs 宽低尾，
  簇边界斜坡位于 0.90-0.95 → 绝对阈值取 0.90（斜坡起点）

## 4. 阈值建议表

| 轨 | 参数 | 建议 | 命中 | 敏感带 |
|---|---|---|---|---|
| ① 检测绝对 | conf < | **0.80** | 框 10.0% | 0.75-0.85 → 7.8-13.3% |
| ② sort 绝对 | conf < | **0.90** | 9.9% | 0.85 → 7.5% |
| ② amount 绝对 | conf < | **0.90** | 23.3% | 0.85 → 19.4%（天生最弱，预算紧可降 0.85） |
| ② side 绝对 | conf < | **0.90** | 3.9% | 0.95 → 7.2% |
| ③ 相对·检测 | 每摄像头 | **p10** | ≈每摄像头最低 1 框 | 中位边界 .908（IQR .790-.938）；p15=.918 / p20=.926 |
| ③ 相对·sort | 每摄像头 | **p20** | ≈次低 | 中位边界 .996（634 摄像头≥3 样本） |
| ③ 相对·amount | 每摄像头 | **p20** | ≈次低 | 中位边界 .942（556 摄像头） |
| ③ 相对·side | 每摄像头 | **p20** | ≈次低 | 中位边界 .997（205 摄像头） |

- 相对轨样本量警示：每摄像头仅 3-11 帧（p10≈最低框，p20≈次低框），是粗边界不是精分位
- dump/person 全量仅 183 框：不建议设阈值，直接全送重标
- 双轨判据：①∪③（检测）、②∪③（属性）；检测 conf 高但属性低的帧只重标属性（省算力）

## 6. 异常发现

1. 尾部 853 ≠ spec 504：n5 12-18/12-23 共 359 帧被 S0 漏计 → 大批日配额压缩至 4,147 守上限
2. n5 12-18 早于部署 symlink 切换（12-23），provenance 存疑；但 schema/行为与主池一致（str
   key、conf≥0.5），按 ≥12-15 规则保留，重标时建议标注 provenance
3. 空帧率 27.8%，06-25 达 39.8%（1,203/3,019）：批量日混入大量无目标/定时快照帧——正是
   zero-trust 要捕获的 FN 候选，也是共识验证器没有输入框的盲区（需单独走「空帧检出」轨）
4. can 类 5,000 帧仅 1 框；illegal/direction 0 产出——类别/属性绑定与部署现实严重脱节
5. person 42 框 / dump 141 框：稀有类极薄，共识 k≥2∧strong≥1 闸门在稀有类上可能凑不齐
6. 数字版 properties.key 在 ≥2025-12-15 数据 0 出现——spec 的两版容错映射保留为防御即可
